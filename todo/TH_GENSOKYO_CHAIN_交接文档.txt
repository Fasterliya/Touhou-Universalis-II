2.1 恶名链（模块①）
  非法扩张(8/地块) / 合法扩张(1/地块) / 吞自由市(x6) ──► 恶名(0-100,隐藏)
      ▲                                                    │
      │                                            月度自然衰减(-1/月)
      │                                                    ▼
  宴会(IO行动,50金,CD12月,-10恶名) ◄──────────── 档位判定(50/75)
                                                    │
                                            弃民修正(贡献x0.7/x0.4)

2.2 惩戒战争+审判（模块②）
  阎魔提案(行动) → 议会辩论(3贤者2/3票过) → 惩戒局势

      ├─ 罪值三源(战斗war_score/时长/拒和)
      ├─ 势力计算(月度, 面板显示)
      ├─ 双条约: 阎魔100分胜利 / 目标国100分反杀
      └─ 结束 → 反杀?(不审判, 反攻扩张行动) / 审判局势(+5团结)
  审判局势 → 阎魔手动(事件3档)或AI自动(罪值<50/50-75/>=75)
      ├─ 轻判: 归还三连(取消附庸+归还核心+释放国家)
      ├─ 中判: +削弱国力(5年)
      └─ 重判: +财富全转移 + 监管国(40%贡金,刑期20-30年)
      团结: 扣5/10/15 + 奖10(审判法±2)

2.3 扩张限制（模块③）
  和约夺地/吞并(成员间) → 有配额? ──是──► 消耗配额 + 合法恶名(+1)
                          │

五、核心机制详解
================================================================================

5.1 议会投票（2/3 贤者票制）
  发起链: 提案行动(effect) → set_parliament_location=scope:actor.capital
        → set_parliament_active=yes → 全员预投no → set_parliament_issue
        → 发起人 vote=yes(标记) → call_io_parliament
  投票权: 3 贤者各 power 200（combined=600，每票 0.333）；
          阎魔/守护/人类村落/占位 power=0（投票权重恒 0 = 实际无票权）
  数学:   2 贤者赞成 = 0.667 > 0.5 通过；1 贤者 = 0.333 不过；
          初始支持度 = 0（阎魔发起=叙事同意，不计票）
  议题:   th_gensokyo_crusade_issue（selectable_for 限领袖）
  通过:   on_debate_passed → enable_situation_effect(th_gensokyo_crusade)
  失败:   on_debate_failed → 清理目标标记

5.2 目标国传递（标记法，全系统唯一机制）
  th_gensokyo_crusade_target_mark：提案时打标 → 局势 on_start/on_monthly 遍历
  IO 成员取目标（save_scope_as=crusade_target）→ 审判局势 on_start 定位后清除；
  反杀结局由惩戒局势 on_ended else 分支清除
  禁止 scope 引用存 IO 变量（语法风险），全部用标记 + 遍历

5.3 罪值（0-100，三源）
  ① 战斗: on_battle_won（root=unit）→ owner 持有目标标记 →
     owner 罪 += scope:war_score（按战果折算；退路=固定值 th_crusade_sin_battle_value）
  ② 时长: 惩戒局势 on_monthly 目标国罪 += 1/月
  ③ 拒和: on_enforce_peace_declined（root 或 scope:recipient 持有标记）→ 罪 += 10
  封顶: clamp 0-100

5.4 审判与判决（3 级模型）
  有效罪值 = 罪值 + 审判法偏移（因果必尝+10 / 劝善-10）
  档位（AI 自动或玩家事件手动设定 th_gensokyo_sentence_tier 1/2/3）:
    轻判(罪值<50): 归还三连
    中判(50-75):   归还三连 + 削弱国力(5年)
    重判(>=75):    归还三连 + 削弱 + 财富全转移(阎魔) + 监管国(40%贡金, 刑期20-30年)
  归还三连: ① every_subject → cancel_subject=prev（取消全部附庸）
            ② every_owned_location: exists previous_owner + is_core_of=previous_owner
               + previous_owner!=阎魔 + country_exists → change_location_owner=previous_owner
            ③ create_country_from_cores_in_our_locations（释放国家）
  财富转移: set_variable value=gold → set_gold=0 → 阎魔 add_gold=var:temp
  刑期: 240 月基础 + (罪/10)年 + 审判法±2年（因果必尝+24月/劝善-24月），封顶 360 月
  团结: 扣 5/10/15（按档）；奖 10±2（审判法：因果必尝+2/劝善-2）
  审判标记: th_gensokyo_judged（永久，后续接口用）

5.5 监管国（subject_type）
  贡金: subject_pays=subject_pays_regulated（scaled_gold 0.4 = 收入40% = 普通附庸2倍，
        持续至刑满，cancel_subject 自动停止）
  约束: level 0 / can_be_annexed=no / subject_can_cancel=no / overlord_can_cancel=no /
        has_limited_diplomacy=yes / allow_declaring_wars=no / will_join_independence_wars=no /
        can_change_rank=no / can_change_heir_selection=no / 全 visible/enabled=no /
        overlord_modifier 空（宗主无特权）
  刑满: on_monthly 倒计时归零 → scope:overlord cancel_subject=prev → 团结+5 → 释放独立

5.6 双条约（互不可见）
  th_gensokyo_crusade_triumph: potential=战争含惩戒CB + winner=阎魔（leader）
    effect: loser 打 defeated 标记 + winner 威望10 + 贡献10
  th_gensokyo_crusade_counter: potential=战争含惩戒CB + winner 持目标标记
    effect: winner 打 countered 标记 + 威望20
  反杀流程: 目标国100分提出反杀条约 → 战争结束 → 局势检测 is_at_war=no →
    结束 → on_ended 反杀分支（不审判，清 target_mark）→ 反攻扩张行动解锁
    （potential= countered 标记 + 局势可见；配额+2，CD 12 月）

5.7 包围网（行动制）
  阎魔: 局势 on_start 自动宣战（决议通过即开战）
  成员: 局势面板行动 th_gensokyo_join_crusade（type=situation，potential=IO成员+非目标）
    effect: 未交战者 declare_war_with_cb（惩戒CB）+ 贡献+5 + 参战标记
  AI: ai_will_do 对目标敌意>=50 → +100 倾向

5.8 恶名链
  来源: 非法扩张+8/地块、合法扩张+1/地块、吞自由市 x6（48/次，clamp 100）
  衰减: 月度 -1（th_notorious_decay_monthly_value）
  宴会: -10（price 50，CD 12 月）
  弃民: 恶名>=50 → 贡献 x0.7；>=75 → x0.4（侵入骨架月度公式）
  查看: IO 行动栏"查看声望"（effect 空，desc=[actor.Custom('th_gensokyo_notorious_tier')]）
  接口: th_gensokyo_notorious_influence_interface_effect（左右法律，空实现待骨架）

5.9 自由市保护
  和约割让自由市地块(on_took_location): 敌意bias 1250 + 恶名x6 + 团结扣10
  吞并自由市国家(on_annex): 同上（兜底）
  外界宣战自由市(on_war_declared): 三贤者 join_war_as_defender（神罗式，
    trigger 限宣战者非成员 → 成员间吞并不触发保护）
  人类村落互相吞并: 只吃惩罚链，不吃贤者参战

5.10 扩张限制
  配额: th_gensokyo_expansion_quota（总）/ _quota_used（已用），发放接口
        th_gensokyo_expansion_quota_grant_effect（小卖铺调用，上限 4）
  合法判定: quota_used < quota（触发器 th_gensokyo_has_authorized_expansion_trigger）
  和约夺地/吞并成员: 合法→消耗配额+恶名1；非法→惩罚链（敌意bias 50+恶名8+团结2/地块）
  代价修正（互斥挂载，月度刷新）: 授权 x0.25 / 异变 x1.25 / 私自 x1.5
    （antagonism_taking_land_giving_modifier 字段）
  异变豁免接口: th_gensokyo_in_incident_trigger（always no，异变系统实现后替换）

5.11 团结度
  月收入: 基础 0.1 + 和平 0.2 + 成员数 x0.002（total_members）
