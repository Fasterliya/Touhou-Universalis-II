## 0. 设计总纲

> **一条贯穿五时代的权力转移主线**：早期贤者是幻想乡唯一的秩序来源——异变由议会**把关并指定解决者**、扩张需**贤者授权**、惩戒由**贤者宣告**；随着异变由自告奋勇的**幻想乡守护**解决、功绩累积，守护逐步在体系中争取主导权，贤者的职能一项项被接管、存在感逐步淡出。至第五时代，贤者仅余「结界守卫」与议会否决权，执行权尽归守护。

三层机制目标：

| 层 | 内容 |
|----|------|
| **叙事弧** | 贤者把关 → 守护自荐 → 守护主导 → 贤者退居结界守卫 |
| **进程变量** | `guardian_legitimacy`（守护声望）↔ `sage_relevance`（贤者存在感） |
| **机械骨架** | 异变主导权三阶段 + 权力迁移阈值 + 守护席位票选 + 双向制衡 |

## 1. 进程变量（核心机制）

### 1.1 守护声望 `th_gensokyo_guardian_legitimacy_var`（0–100）

| 来源 | 值 | 说明 |
|------|-----|------|
| 解决异变 | +5~15（按烈度/参与） | 主来源 |
| 获得守护席位 | +10 | 当选即加 |
| 惩戒战争胜利 | +10~20 | 接 A4 |
| **经营行为** | +1~5 | 宴会(A8/B7)、论功行赏(A7)、异变调查等 1.0.0 经营行为小幅计入 |

| 衰减 | 值 | 说明 |
|------|-----|------|
| 惩戒战败 | −10~20 | |
| 贤者处罚 | −5~15 | 接「反统一张力」贤者阻挠 |

### 1.2 贤者存在感 `th_gensokyo_sage_relevance_var`（0–100，IO 变量）

- **开局 = 100**。
- **衰减**：时代门 + 异变累积双驱动——`age_3` 起每解决一次异变按守护声望比例微降；`age_4`/`age_5` 各设时代衰减系数。
- **下限 = 20（结界守卫态）**：不再衰减，保留大结界修正 + 议会否决权，执行权已全交守护（见 §6）。

## 2. 异变主导权三阶段

### 阶段一：时代 1–2（贤者时代）

- 异变触发后，**仅贤者能通过 T2「指定异变解决者」**指派解决者。
- **软门**：贤者有优先指定权；**12 个月**内未指定，任何人可自由认领（防 AI 卡死异变流程）。
- 扩张需 T5 贤者授权；惩戒由贤者 A4 宣告。体系为贤者中心。

### 阶段二：时代 3（过渡）

- `age_3` 解锁守护席位（1 席起，见 §4）。
- 守护可通过新行动「主动请缨」自荐主导异变，与 T2 并行。
- 解决异变 → 守护声望++；贤者存在感开始衰减。

### 阶段三：时代 4–5（守护时代）

- 守护可「接管」贤者未处理的异变（耗守护声望）。
- 守护可绕过贤者授权扩张（代价：与贤者关系−、触发贤者阻挠事件）。
- 权力迁移随存在感阈值档推进（见 §3）。

## 3. 权力迁移阈值（按 `sage_relevance` 档）

| 存在感档 | 迁移 | 说明 |
|----------|------|------|
| ≤ 60 | **扩张授权迁移**：T5 授权资格从贤者议会 → 守护可批 | 守护开始掌扩张审批 |
| ≤ 40 | **异变指定迁移**：异变解决者由守护主导，T2 贤者指定失效 | 异变主导权移交 |
| ≤ 20 | **惩戒宣告迁移**：A4 惩戒宣告守护可发 | 执行权全交守护，贤者退居结界守卫态 |

> 迁移是**单向可逆性待定**：守护崛起后可回退（贤者回调）吗？默认**不可逆**（保叙事线性），可在 §8 平衡项复核。

## 4. 守护席位

### 4.1 席位扩容（对齐 P5 §6.2）

| 时代 | 席位 | 说明 |
|------|------|------|
| age_3 | 1 席 | 解锁 |
| age_4 | 2–3 席 | 依法律/贡献扩容 |
| age_5 | 3–5 席 | 满额 |

### 4.2 产生方式

- **每 20 年**一次票选：幻想乡IO 全体成员投票，按**贡献度/影响力权重**排序，票高者当选守护。
- 要求（P5 §6.2）：未接受过审判 + 恶名低 + 与贤者关系良好。
- 贤者保留**否决权**：可一次否决票选结果，但需付出代价（耗威望/团结，且随存在感下降更贵）。

### 4.3 守护权力

- 自荐主导异变（阶段二起）→ 接管异变（阶段三）。
- 守护授权扩张（≤60 迁移后）。
- 惩戒宣告（≤20 迁移后）。
- 「统一进程」法律（§5 张力）。

## 5. 双向制衡（反统一张力，P5 §6.3）

| 方向 | 形态 |
|------|------|
| **贤者存在感高 → 压制守护** | 守护行动更贵（消耗 × 系数）/ 守护声望增益降低 / 守护难当选 |
| **守护崛起 → 贤者阻挠** | 触发「贤者阻挠」事件：与贤者关系−、临时 debuff、统一立法受阻、守护声望− |

> 贤者/阎魔始终维护幻想乡的**稳定、破碎与传统**；守护席位的**统一进程**与其守序立场形成机制性拉锯。

## 6. 贤者式微的具体形态

随 `sage_relevance` 下降：

1. **议题/行动消耗上升**：团结/威望消耗 × 衰减系数。
2. **议会支持阈值上升**：贤者议会议题更难通过。
3. **权力迁移**：授权/异变指定/惩戒宣告按 §3 档位移交守护。
4. **威望月度衰减加速**：在 §2.2 规则（团结度驱动）基础上 × 系数。
5. **团结度使用权从独占 → 共议**：落实 P1 §1.2「使用权限仅贤者」在守护时代被稀释。

**终态（存在感 = 20 结界守卫态）**：贤者保留大结界修正（A4 结界守卫）与议会否决权，其余执行权全交守护；存在感不再衰减。

## 9. 编码铁律（沿用 1.0.0 路线图）

- `.txt` / `.yml` → UTF-8 BOM；`main_menu/setup/start/` 例外 → 无 BOM；`.gui` / `.csv` → 无 BOM
- 修饰符数值 ≤5 位小数；变量读用 `var:`；`change_variable` 用 `add =` 不用 `value =`
- 事件必须含 `outcome = ...`；事件 ID 用 `namespace.integer (1-9999)`
- 写前对存疑语法输出 **Verification** 行（Step 2/3 + path + quote）
- 新 modifier 写前核对 `reference_game_files/.../00_modifier_types.txt`
