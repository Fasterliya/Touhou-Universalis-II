# Touhou Universalis II — 1.0.0 东方风味措施清单

> 项目: Touhou Universalis II (EU5 完全转换MOD)
> 生成日期: 2026-08-08
> 状态: 已确认，纳入 1.0.0 范围（实施时并入 `todo/TH_1.0.0_ROADMAP.md` 对应里程碑）
> 原则: 不加新系统，全部在既有机制上叠风味；成本低、东方味浓

---

## A 档 — 必装（强化既有系统，≈零新增系统成本）

### A1. 弹幕力改名 + 文化组差异化加成
- 弹幕战火力值对内命名/本地化用「灵力/弹幕力」。
- 按 113 文化（12 文化组）给火力差异化加成：
  - 鬼族/力量流 → 基础火力高（近战风格）
  - 天狗/速度流 → 追加攻击/先手修正
  - 魔法使/月之民 → 灵力流加成
- 载体：`script_values/th_danmaku_firepower_value.txt` 内按文化组 if 分支。
- 里程碑：M1

### A2. 符卡宣言 + 败者体面认输（领土无损）
- 弹幕战决斗事件文本做「符卡宣言」（如"梦幻红魔"），胜负双方各有风味事件。
- 败者付贡品/名誉损失，但**领土无损** → 强化"幻想乡无死斗"设定。
- 载体：`events/th_danmaku_events.txt` 的胜负分支 + 本地化。
- 里程碑：M1

### A3. 称号系统
- 用 static modifier 命名称号：「异变解决者」「宴会之王」「幻想乡最速」「弹幕女神」等。
- 胜利/活动累积称号，带轻微修正，可叠加（收集乐趣）。
- 载体：`main_menu/common/static_modifiers/` + 本地化 + 事件授予。
- 里程碑：M1（授予点散落 M1/M3）

### A4. 大结界 = 团结度的世界观实体
- 用 auto_modifier 把 `th_gensokyo_unity_var`（团结度）映射为结界强度：
  - 团结度高 → 防御/稳定 buff（结界稳固）
  - 团结度低 → 异变频发 debuff（结界衰弱）
- 载体：`auto_modifiers/th_auto_modifier.txt` 扩展（可参照已有恶名四档写法）。
- 里程碑：M2

---

## B 档 — 低成本风味行动（全部采纳）

### B5. 御守免罚
- 神社系国家可消耗「信仰/贡献」兑换御守，抵消一次敌意/恶名累积。
- 服务 1.0.0 规避路径，风味 100%。
- 载体：`country_interactions/` 或事件链 + 变量计数。
- 里程碑：M2

### B6. "来寻麻烦"事件池
- 5–6 个精简事件：妖精捣乱、天狗造谣、鬼族搬酒、幽幽子蹭饭、月兔送信等。
- 每个 2–3 选项，对应不同资源回报（贡献/威望/关系/恶名权衡）。
- 载体：`events/th_trouble_events.txt` + 本地化。
- 里程碑：M3

### B7. 宴会主题化 + 宴会异变
- 宴会主题选项（赏樱/赏月/祭典/庆功）→ 不同 buff。
- 小概率(2–5%)触发「宴会异变」（醉酒八云紫开隙间、萃香偷酒跑路）→ **宴会变成 M3 异变入口**。
- 载体：宴会主事件选项 + `th_incident_events.txt` 衔接。
- 里程碑：M2（宴会行动）/ M3（异变入口）

### B8. 贤者个人信任
- 三位贤者（紫/华扇/山童）各一信任变量，而非统一威望。
- 角色感：不同贤者的信任影响不同事务（授权/调停/弹幕战偏袒）。
- 载体：`th_sages_council_effects.txt` 扩展 + 数组变量 + 少量事件。
- 里程碑：M3

### B9. 人间之里中立区张力
- 邻接人类村落地块的弹幕战/扩张 → 额外敌意累积。
- 逼玩家"别在村门口闹"，强化人妖分界。
- 载体：`on_action/th_gensokyo_io_monthly.txt` 检测 + 敌意修正。
- 里程碑：M2
