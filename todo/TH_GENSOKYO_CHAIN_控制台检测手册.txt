0.1 启动调试模式（必须）
  Steam: 右键游戏 → 属性 → 启动选项 → 填 `-debug_mode` → 启动
  非 Steam: eu5.exe 快捷方式目标末尾加 `-debug_mode`

0.2 控制台打开
  QWERTY 键盘: `` ` ``（Esc 下方）或 Alt+C；也可 Shift+2
  Tab 自动补全；↑↓ 历史

0.3 核心命令速查（本手册全部检测基于以下）
  tag <TAG>            切换控制国家（T25=阎魔 T05/T13/T83=三贤者 T00=红魔馆 T03=人类村落）
  effect <脚本>        在指定 scope 执行效果（核心：effect c:T05 = {...}）
  trigger <触发器>     测试触发器，输出 yes/no（变量二分验证法）
  tick_day <N>         推进 N 天（触发月度用 tick_day 30）
  monthly_situation <key>  对局势执行一次月度 tick（手动触发 on_monthly）
  situation <key>      强制启动局势（无视 can_start）
  event <id> [target]  触发事件
  policy <policy>      添加政策
  cash/manpower <N>    加资源
  declarewar <TAG>     宣战
  YesMan               全员接受模式
  InstantWar           即时战争
  switchlanguage simp_chinese  重载本地化（切走再切回）
  Log.ClearErrorLog    清空 error.log（测试前后对比）
  gamelog / error      查看日志

0.4 热重载限制（重要）
  common/ 脚本修改后必须重启游戏才生效（含本 MOD 全部新增文件）
  本地化 yml 例外: `switchlanguage english` 切走再 `switchlanguage simp_chinese` 切回即可重载

0.5 通用变量查看法（无 print 命令）
  EU5 无"打印变量值"命令。统一用 trigger 二分法：
    trigger c:T05 = { var:th_gensokyo_notorious_reputation_var >= 50 }
    → 输出 yes/no，调整阈值逼近实际值
  或游戏内 UI：IO 面板（团结度 subheader）/ 恶名查看行动 tooltip / 局势面板

0.6 测试前存档
  save <文件名>  — 每模块测试前存档，出问题 load 回滚

0.7 运行时错误签名速查（2026-08-07 实测发现，已修复；复测时若再现即回归）
  S1 "Invalid left side during comparison 'var'"
     → 裸 var: 在 customizable_localization 调用链（含间接经 scripted trigger）失效
     → 已修复：chain_triggers 全部比较位置改 root.var:（带前缀形式 base game 实证可用）
  S2 "antagonism trigger [ Null object! Field: target ]"
     → select_trigger enabled 嵌套块内 root=null ——已移入 interaction_source_list
  S3 "Undefined event target 'target'"
     → target_flag=target 显式指定不可靠 ——已改 th_target_country
  S4 ai_will_do 遍历内 antagonism target=root 失效 ——已改嵌套 prev
  S5 "This scope doesn't support variables. Scope: empty"（打开 IO 面板报错）
     → generic action potential 顶层 root=empty，has_variable 报错
     → 已修复：potential 变量触发器用 scope:actor ?= 包裹（counter_expansion）
  S6 "Variable not of the 'value' scope type. Type: empty"（点宴会报错）
     → value = -script_value 负号引用解析为空 → 已改 subtract
     → v5 升级：scope:actor 嵌套 + script_value 名参数组合不可靠 → 参数数字化
  S7 "Invalid left side during comparison 'var'"（查看声望刷屏）
     → customizable_localization 变量数值比较彻底不支持（含 scripted trigger 间接）
     → v5 修复：放弃 Custom() 档位，desc 改数值显示 GetVariable（base game 先例格式）
  S9 "no variables in scope"（时间推进报错）
     → generic action ai_will_do root=IO 无变量 → 已删恶名 if 块
  S10 "Event target link 'var' returned an unset scope"（裸 var: 数值比较）
     → 裸 var: 数值比较（>/>=/</<=）在 scripted effect limit / ai_will_do 报错
     → 已修：notorious_effects root.var: / regulated_state root.var: /
       crusade_effects scope:crusade_target.var:（?= 存在性与参数位置安全）
  S11 "not being set" / change_variable empty（成员变量缺失，新局）
     → on_game_start init 空转 → 已加月度变量兜底（5 组 has_variable 守卫 set 0）
  回归: Log.ClearErrorLog → 跑 5 分钟（含点宴会/开 IO 面板/时间推进/新局验证）→ error 复查零新增

一、议会 2/3 贤者票制（最高优先级）
════════════════════════════════════════════════════════════════════════

验证点: 阎魔提案 → 1 贤者投不过 / 2 贤者投通过 → 惩戒局势启动

步骤:
  1. tag T25（阎魔）；cash 1000
  2. 给目标加恶名（提案资格，2026-08-14 改恶名驱动）:
     effect c:T00 = { set_variable = { name = th_gensokyo_notorious_reputation_var value = 60 } }
     trigger c:T00 = { root.var:th_gensokyo_notorious_reputation_var >= 50 }   → 期望 yes
  3. 游戏内: 打开幻想乡 IO 面板 → 点"发起惩戒战争提案" → 选 IO → 选目标 T00
     观察: 议会辩论启动（IO 面板出现投票栏）
  4. 验证初始支持度=0（阎魔发起不计票）:
     trigger international_organization:th_gensokyo_io = { is_active_parliament = yes }  → yes（议会还在=未通过）
  5. 模拟 1 贤者赞成:
     effect c:T05 = { participate_in_parliament = { international_organization = th_gensokyo_io vote = yes } }
     tick_day 1
     trigger international_organization:th_gensokyo_io = { is_active_parliament = yes }  → 期望 yes（0.333 不过）
  6. 模拟第 2 贤者赞成:
     effect c:T13 = { participate_in_parliament = { international_organization = th_gensokyo_io vote = yes } }
     tick_day 1
     trigger international_organization:th_gensokyo_io = { is_active_parliament = yes }  → 期望 no（0.667 通过）
  7. 通过后自动启动惩戒局势:
     trigger c:T25 = { can_see_situation = situation:th_gensokyo_crusade }  → 期望 yes
  8. 阎魔自动宣战:
     trigger c:T25 = { is_at_war_with = c:T00 }  → 期望 yes
  9. 失败路径（可选）: 重打标重新提案 → 3 贤者全反对 → 议会结束但局势未启动

预期结论: 2 票 0.667 过 / 1 票 0.333 不过；阎魔无投票权（power=0）
           另验证: tag T00 尝试投票 → effect c:T00 = { participate_in_parliament = {...} } 后支持度不变
