三、席位解锁机制详解
================================================================================

【设计】法律 th_gensokyo_seat_unlock_law（type = international_organization，
requires_vote = no，单政策开关）：
  - 政策 th_gensokyo_seat_unlock_policy 存在 = 席位解锁
  - 政策移除 = 席位锁定
  - 无 forbids_no_policy（单政策 + 该标签会导致无法回到锁定态！）

【席位】th_gensokyo_io_seat_special_status（max_countries = 1，占位）：
  can_bestow_trigger = {
      is_member_of_international_organization = scope:recipient
      scope:recipient = {
          international_organization_has_policy = policy:th_gensokyo_seat_unlock_policy
          "num_countries_with_special_status(special_status:th_gensokyo_io_seat_special_status)" < 1
          NOT = { any_international_organization_member = {
              this != root
              var:th_gensokyo_personal_contribution_var > root.var:th_gensokyo_personal_contribution_var
          } }
      }
  }
  auto_bestowal_trigger = { always = yes }      # can_bestow 满足 → 自动授予
  auto_rescind_trigger = { NOT = { scope:recipient = {
      international_organization_has_policy = policy:th_gensokyo_seat_unlock_policy } } }  # 政策关→收回

【范式来源】base game union.txt senior_partner：
  - can_bestow_trigger 内 scope:recipient 引用 international_organization_has_policy
  - auto_bestowal = always + can_bestow 门控 = "满足条件即自动"
  - auto_rescind 用政策 NOT 条件（本实现无 OR，规避引擎 OR/NOR 禁令）

【个人贡献度】月度脉冲 th_gensokyo_io_monthly.txt 已实现：
  th_gensokyo_temp_contribution = 税基/1000 → th_gensokyo_io_contribution_var_add_effect
  → th_gensokyo_personal_contribution_var（国家变量，每月累加）

四、控制台测试命令
================================================================================

进游戏控制台（~）输入，均基于 effect/trigger 命令（选定国家 scope 执行）：

# 1. 解锁政策（激活席位解锁）
effect international_organization:th_gensokyo_io = { add_policy_to_international_organization = policy:th_gensokyo_seat_unlock_policy }

# 2. 锁定政策（移除 → 席位自动收回，等待月度评估）
effect international_organization:th_gensokyo_io = { remove_policy_from_international_organization = policy:th_gensokyo_seat_unlock_policy }

# 3. 强制授予席位（country = root 为选中国家；也可 country = c:T25）
effect international_organization:th_gensokyo_io = { international_organization_add_special_status = { type = special_status:th_gensokyo_io_seat_special_status country = root } }

# 4. 强制撤销席位
effect international_organization:th_gensokyo_io = { international_organization_remove_special_status = { type = special_status:th_gensokyo_io_seat_special_status country = root } }

# 5. 验证政策状态（输出 yes/no）
trigger international_organization:th_gensokyo_io = { international_organization_has_policy = policy:th_gensokyo_seat_unlock_policy }

辅助：io_stats 切换 IO 调试统计；help reload 查看 reload 能力。

【热重载限制】common/ 脚本启动时加载，修改必须重启游戏。
本地化可用 switchlanguage english → switchlanguage simp_chinese 强制重载。
