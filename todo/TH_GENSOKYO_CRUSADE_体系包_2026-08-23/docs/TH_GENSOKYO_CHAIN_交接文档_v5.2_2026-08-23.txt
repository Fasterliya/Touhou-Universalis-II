第 1 章：特殊附庸降级 BUG——最终结论（v5.2 新增，最高价值）
================================================================================

  现象：make_subject_of 创建的监管国跨月被引擎重置为普通 vassal。
  历程：enabled 假设（F10，无效）→ on_monthly 假设（F15/F16，错误归零但降级
        依旧——报错只是噪音非根因）→ 参考实现 yky_shinju_guard 逐字段对比 →
        三件套对齐 → 用户实测修复。

  修复组合（对照参考 yky_shinju_guard 神树护卫国）：
  ① 隐藏写法：visible_through_diplomacy/treaty + enabled_through_diplomacy/treaty
     = no 系列（参考无顶层 visible/enabled；顶层字段被牵涉进重置）
  ② level = 3（原 0 = "名义附庸"；注意 tributary 也是 0 且合法——
     level=0 单独不必然导致降级，单一因子未隔离）
  ③ annullment_favours_required = 20（外交废除所需人情，base game 17 类型全带）

  字段正名：can_be_annexed（非 can_annex）/ monthly_favor_gain（非 loyalty_modifier）
  / subject_pays（非 tribute）——旧模板用了错误字段名，已修正。

  详见: 维基代码库\_分析报告\复盘报告_特殊附庸_2026-08-23.md（K-S1~K-S5）

第 3 章：体系全景（53 文件，见体系包 README 二节）
================================================================================

  开会（IO 议会）→ 惩戒战争 → 结算条约 → 审判 → 监管国（刑期/释放/保护）
  关键链路与修复映射：
  - 提案开会: propose_crusade + crusade_issue + io_parliament + IO 定义 has_parliament
  - 规则投票: debate_start_effect（预投 no + 翻转 yes——EU5 不能直接投反对票）
  - 通过激活: on_debate_passed → leader_country 内 enable+activate（tooltip 铁律）
  - 宣战: 局势 on_start declare_war_with_cb
  - 加入: join_crusade（any_current_war 目标国 scope + war=prev 嵌套）
  - 结算: triumph/counter 条约 + 免制裁
  - 审判: trial 局势 + 4 档判决（judge_core_effect）
  - 监管国: regulated_state（level=3/through_* 隐藏/annullment）+ pulse 倒计时
    + 脱离彼岸事件 + 阎魔保护（overlord_protects_external + on_war_declared 兜底）
