第 1 章：本次实测根因库（新增，最高价值）
================================================================================

  1.11 enable_situation_effect ≠ 激活局势（局势不启动根因）
      - enable_situation_effect 只 set_global_variable enabled_situation_$type$
        （situation_effects.txt:5-14 实证），不直接激活局势
      - 激活依赖月度 spawn 检查；实测 monthly_spawn_chance = 1 +
        can_start = has_enabled_situation_trigger 时局势不自动启动
      - base game 完整模式 = 双调用（flavor_tim.txt:628+653）：
        enable_situation_effect（设全局变量）+ activate_situation（立即激活）
      - activate_situation 需 can_start=true（维基）→ enable 必须先行
      - 波及：惩戒局势（议会通过后）+ 审判局势（惩戒 on_ended 后）——同款 bug

  1.12 any_current_war 遍历 scope = 当前 root 参与的战争（join 单独开战根因）
      - any_current_war/random_current_war 枚举「当前 root 参与的战争」
      - 原写法在 scope:actor 内 → 枚举执行者（尚未参战）的战争 = 恒空 →
        if 失败 → 走 else 兜底 declare_war_with_cb → 每国单独开战
      - error.log 实证：DBG_JOIN_ELSE（th_gensokyo_join_crusade.txt:124）多次出现
      - 胡斯先例（hussite_wars_actions.txt:747-764）：遍历写在目标国 c:BOH 块内，
        条件 attacker_leader = 领袖 + defender_leader = 目标
      - 已复刻：scope:crusade_target ?= { if { any_current_war {...} }
        random_current_war { scope:actor = { join_war_as_attacker = { war = prev
        call_in_subjects = yes } } } }
      - 注意：else 兜底宣战必须保持 scope:actor 嵌套（declare 执行者 = 发起国）

  1.13 script value 引用缺失变量 → 整个公式返回 none（投票权重隐藏根因）
      - var:th_gensokyo_personal_contribution_var 未设置（旧档/后加入成员）→
        "Failed to fetch variable" + 公式返回 none 类型 →
        special_status_power 失效（game.log "Value of wrong type ... Got value of
        type 'none'" at th_gensokyo_io.txt:31/201）→ 议会投票权重异常
      - 修复：script value if 守卫包装（维基 Variable:898 / 反模式 142 同款）：
        if = { limit = { has_variable = X } add = var:X }——缺失按 0 计

  1.14 on_action trigger 裸 key 被当 event target link 解析失败
      - is_member_of_international_organization = th_gensokyo_io（裸 key）→
        "Failed to find a valid event target link 'th_gensokyo_io'"
        （game.log:4107 实证）→ trigger 恒 false → 月度脉冲 effect 永不执行
        → 免制裁倒计时/贡献度累计全失效
      - 修复：加前缀 international_organization:th_gensokyo_io
      - 另：th_gensokyo_io_monthly.txt:22 有 modifier:country_tax_base
        （Non-existent modifier type，v5.0 根因 1.7 同款陷阱漏修一处）→ 裸引用

  1.15 开局价值观矛盾消除（P0-3）
      - 三方设置：政府模板 0 / io_init_setup -100 / chain_init 100
      - on_game_start 内 -100 与 100 并存，执行顺序不确定 → 最终值不可靠
      - 用户已拍板 100（v5.0 第 3 章「开局价值观 100 采纳」）→
        删除 io_init_setup 的 -100 → 最终确定性 = 100（chain_init 唯一负责）

  1.16 situation effect 的 tooltip 文本含 [COUNTRY.GetName]——scope 渲染失败族（新）
      - THIRD_ENABLE_SITUATION_EFFECT / THIRD_DISABLE_SITUATION_EFFECT 的本地化
        文本均含 [COUNTRY.GetName]（scripted_effects_l_*.yml:818/824 实证）；
        THIRD_ACTIVATE_SITUATION_EFFECT / THIRD_END_SITUATION_EFFECT 只含
        [SITUATION.GetName]（安全）
      - 在 IO/situation scope 调用 enable/disable_situation_effect → tooltip 渲染
        失败（error.log "Data error in loc string 'THIRD_ENABLE_SITUATION_EFFECT'" +
        "Promote 'COUNTRY' returned nullptr" 刷屏实证）→ custom_description 内
        set/remove_global_variable 执行中断 → 全局变量未设/未清
      - 后果链（议会重复开会根因）：enable 中断 → 全局变量未设 → activate 的
        can_start 不满足 → 局势不启动 → propose allow 不挡 → 再次提案 → 重复开会、
        议题一样（议题池只有惩戒议题有效，3 空壳无 special_status 引擎不调度）
      - disable 中断 → 全局变量残留 → 局势结束后下月自动重启（无需议会）
      - 修复：enable/disable_situation_effect 全部挪到 leader_country（国家 scope）
        调用（F8/F9/F12）；activate/end_situation 任何 scope 安全
      - 教训：base game effect 的 tooltip 数据函数依赖调用 scope——非国家 scope
        调用前必查 effect_localization 文本

  1.17 监管国过月变普通附庸（真正根因：subject on_monthly 引擎不可靠）
      - 【初判】enabled = always no → 改 yes（F10）——实测无效，排除
      - 【真根因】subject_type 的 on_monthly 回调在 EU5 引擎中不可靠：
        readme:23 文档化 root=subject，但 base game 18 个类型全部零实现；
        运行时实证 root 解析为无效空国家（error.log "Scoped object of type
        'country' is not valid (国家"国家"（---）)" at :86/:98，单会话 4480 行）→
        每月报错 → 引擎 subject 月度维护异常 → 类型被重置为普通附庸
      - 【修复】F15：删除 regulated_state on_monthly（消除报错源，on_enable 保留——
        base game 9 类型有 on_enable 实现，可靠）
        F16：刑期倒计时/释放迁移至 th_gensokyo_io_monthly_country_pulse
        （country on_action pulse，root=国家 可靠；监管国保持 IO 成员）
      - 【教训】subject 的 on_monthly 与 on_io_parliament_started 同族：
        readme/定义存在但引擎行为不可靠——非国家 scope 的官方回调先用 base game
        使用量验证（0 实例 = 高危信号）

  1.18 刑满释放原为静默操作（无事件）
      - regulated_state on_monthly 归零直接 cancel_subject，玩家无感知
      - 修复：新建「脱离彼岸」事件 th_gensokyo_trial_events.2（root=被监管国，
        事件内 cancel_subject + 团结奖励 + 清变量），on_monthly 归零改为
        trigger_event_non_silently；控制台触发：event th_gensokyo_trial_events.2 [c:TAG]

  1.19 宗主保护附庸的机制（阎魔保护义务，F13/F14）
      - subject_types/readme.txt:65：overlord_protects_external（宗主是否保护附庸
        免受外部攻击，默认 yes——base game 18 类型无一显式设置，依赖引擎默认）
      - subject_types/readme.txt:34：join_defensive_wars_always（"does one country
        automatically join defensive wars with the other"——关系双向自动加入防御战；
        学园自治区同款先例：隐藏类型 + always = yes，维基 Subject_types:303）
      - on_war_declared 钩子（_hardcoded.txt:2054）：root=country, scope:actor=宣战国,
        scope:recipient=被宣战国, scope:war=战争——文件内自由市保护先例
        （贤者 join_war_as_defender = { war = scope:war }）同构
      - F13：监管国加 overlord_protects_external = yes + join_defensive_wars_always
      - F14：on_war_declared 追加 th_gensokyo_regulated_protection——监管国被宣战
        → 阎魔（leader_country）强制 join_war_as_defender（is_at_war_with 防重 +
        惩戒 CB 排除防自己打自己）
