## 二、精华知识点（已沉淀）

### K-S1：隐藏写法——`visible_through_*` 系列替代顶层 `visible/enabled`
- 参考实现（yky_shinju_guard）无顶层 `visible`/`enabled`，用 `visible_through_diplomacy/treaty` + `enabled_through_diplomacy/treaty` + `subject_creation_enabled`/`release_country_enabled`/`creation_visible` = no
- 顶层 `visible`/`enabled` 被牵涉进重置 bug；同写法的 satori_vassal（开局附庸）未验证，**待批量排查**
- 证据：yky_shinju_guard.txt:7-13（参考实证）+ 修复后用户实测

### K-S2：`level` 语义修正
- 维基原记："0级=名义附庸"——**tributary 即 level = 0 且合法**（field_verify 实证 tributary.txt:6）
- **level = 0 单独不必然导致降级**；本次修复 = 组合（level≥1 + through_* + annullment），**单一因子根因未隔离**（如实记录，待后续可单因子验证）
- 证据：base game tributary.txt:6 / yky_shinju_guard.txt:4（level=3）

### K-S3：`annullment_favours_required` 必补
- official readme:52 实证（"number of favours needed to annul this membership diplomatically"）；base game 17 类型全带（10-30）
- 缺省可能改变引擎对类型解除/变更的默认行为
- 证据：field_verify（official + baseGame 17 处）

### K-S4：on_monthly `root.var:` 不可靠（纠偏）
- 报错真实（error.log 实证）但**非降级根因**（F15 后错误归零、降级依旧）
- 周期逻辑仍应走 country pulse（可靠）；on_enable 可靠（base game 9 类型）

### K-S5：字段正名
- `can_be_annexed`（非 can_annex）/ `monthly_favor_gain`（非 loyalty_modifier）/ `subject_pays`（非 tribute）——旧模板用了错误字段名，已一并修正
