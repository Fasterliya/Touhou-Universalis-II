## 一、设计总纲

### 1.1 三IO定位矩阵

| IO | 成员 | 领袖 | 议会 | 核心角色 | 现有状态 |
|----|------|------|------|----------|----------|
| th_gensokyo_io（幻想乡） | 全体95国 | 阎魔 T25 | has_parliament=no（待激活） | 全体国家的秩序框架 / 敌意-惩戒载体 | ✅ 定义完整 |
| th_sages_council_io（贤者议会） | 三贤者 T05 T13 T83 | 无 | ✅ 已激活 | 团结度的使用权 / 异变观战与决策 | ✅ 定义完整 |
| th_human_village_io（人间之里） | 待定 | 无 | no | 人类聚居保护 / 贸易繁荣 | ⚠️ 41行框架 |

### 1.2 资源双轨总图

```
【幻想乡团结度 th_gensokyo_unity_var】IO级共享变量 (0-100)
   来源: 幻想乡和平 / 异变成功解决 / 宴会活动 / 释放国家 / 停战调解 / 惩戒胜利 / 贤者干预
   损失: 非法扩张 / 人间之里被侵占 / 异变失控 / 外界势力入侵 / 大规模战争
   👉 显示于幻想乡IO面板，但【使用权限仅贤者】—— 由贤者议会议会投票决定用途

【个人贡献度 th_gensokyo_personal_contribution_var】国家级变量 (0-∞)
   来源: 经济实力(on_monthly) / 参与异变解决 / 宴会活动 / 维护稳定工作 / 惩戒战争参战
   用途: 换算成【个人影响力】→ 议会投票权重 / 购买贤者服务 / 请求合法扩张 / 竞争守护席位

【个人影响力 th_gensokyo_personal_influence_var】国家级变量 (0-∞)
   = 贡献度的"政治化"投资结果，决定在幻想乡议会辩论中的权重占比
   投资1:1换算，但权重只读影响力（贡献度本身不直接投票）

【幻想乡恶名 th_gensokyo_notorious_reputation_var】国家级隐藏变量 (0-100)
   积累: 非法扩张 / 过度好战姿态
   削减: 宴会活动 / 友善事件
   后果: 高恶名→国际弃民：贡献度获取大减 / 失去左右法律能力 / 失去守护席位资格
   👉 异变中扩张（烈度未失控）不计恶名
```

### 1.3 核心循环（玩家的主要玩法循环）

```
贡献度获取 → 投资为影响力 → 议会投票权重↑ / 购买贤者服务
     ↓                                    ↓
 请求合法扩张(2-4块)              或  私自扩张(游戏自带议会)
     ↓                                    ↓
  贤者授权(花费-75%)                 敌意+恶名↑ (异变扩张可豁免恶名)
     ↓                                    ↓
    正常扩张                         敌意超阈值 → 贤者/阎魔宣告惩戒战争
                                            ↓
                                     惩戒战争Situation(包围网) 胜/负
                                            ↓
                                    败→阎魔审判Situation→监管国/罚金/弃土
                                    胜→获得宣称多场扩张
                                            ↓
                                   结算 → 幻想乡团结度回流 / 贡献度结算
```

### 2.4 贡献 → 影响力换算

- **建议 1:1**，投资行动 `th_gensokyo_io_influence_var_add_effect`（已有）
- 议会投票权重 = `special_status_power`（script value，root=country）直接写成 `root.var:th_gensokyo_personal_influence_var`
- 基准建议：影响力 > 0 即有权重，占比 = 影响力 / 全体成员影响力总和
- 权重影响：法律变更投票 / 守护席位选举排序 / 议会议题发起优先度

### 2.5 恶名（th_gensokyo_notorious_reputation_var）

| 行为 | 建议值 | 触发 |
|------|--------|------|
| 非法扩张(每省) | +5~8 | 扩张限制检测 |
| 使用自带议会扩张 | +10 | 同上 |
| 主动宣战幻想乡成员(无CB) | +3~5 | on_action |
| 宴会活动 | -3~5 | 宴会事件链 |
| 战争罪/屠城 | +5~15 | 惩戒Situation罪计数 |

**后果阈值**：
- 恶名≥30：贡献度获取 -30%
- 恶名≥50：无法左右法律投票 / 贡献度获取 -50%
- 恶名≥70：国际弃民 / 失去守护席位资格 / 贡献度获取 -70%

## 三、贤者议会子系统（阶段1）

### 3.1 现有样板 — "引入思潮"

已实现链路（最完整样板，后续议题全部复用此模式）：
```
SGUI(枚举目标) → 存IO变量(th_sages_pending_institution) → propose_parliament_issue
→ 议会辩论(2/3票通过) → on_debate_passed(执行效果) / on_debate_failed(资源不退还)
```

### 3.2 新议题清单

| 议题 | 消耗 | 通过效果 | 失败效果 |
|------|------|----------|----------|
| 引入思潮 | 10团结 + 500金 | 全部贤者首都思潮进度100 | 不退还 |
| 引进外界人口 | 20团结 + 1000金 | 贤者首都人口迁移事件链 | 不退还 |
| 指定异变解决者 | 10团结 | 指定国获得解决者buff+特殊事件 | 不退还 |
| 赌局注资 | 5团结 | 该贤者支持目标存入变量 | 不退还 |
| 异变继续发展(EX面) | 15团结 | 异变进入EX阶段 | 不退还 |

### 3.3 扩张授权

**规则**：
- 玩家用贡献度通过宴会等活动取悦贤者 → 获得"合法扩张请求"资格
- 贤者授权扩张的地点**极度受限**：2-4块
- 价格修正（对扩张宣称/吞并的价格）：
  - 独自议会（未经贤者）: +50%
  - 异变中扩张: +25%
  - 贤者授权: -75%
  - 省份数量多 → 额外 +100%～150% 花费
- 非法占用贤者地 → 贤者威信↓ + 恶名↑

**实现**：country_interactions select_trigger 选地点 + price_modifier 计算；授权状态存国家变量。

### 3.4 人间之里保护

- 人间之里（T03等）所有地块受贤者保护
- 人类村落国家无法获得贤者地块的合法宣称
- 人类村落国家作为"自由市"存在：不可被外交吞并，强制吞并 → 敌意+500%
- 对标 HRE 自由市（free_city 范式）

**实现**：human_village特殊席位 modifier + `th_gensokyo_io` 敌意修正 + CB/宣称限制触发器。

## 四、异变系统（Situation + 事件链，阶段2）

### 4.1 触发结构（用户选定：事件链触发）

```
角色发起异变事件(国家事件链) 
   ↓ 例如"异变的萌芽"
activate_situation = situation:th_gensokyo_incident_xxx
   ↓
Situation on_start: 创建烈度变量(初始10) / 阶段=发生 / 登记发起国
   ↓
Situation on_monthly: 烈度随机增长(+1~3) / 玩家调查行动 / 贤者观战
   ↓
结束判定 → on_ended: 结算贡献度 / 团结度回流 / 触发赌局判定
```

### 4.2 Situation 内部结构

- `phase` 变量: 发生 → 发展 → 解决/失控
- `th_incident_intensity_var`: 烈度 0-100
- 参与者列表: global_variable_list 存国家scope
- 解决者: 贤者议会指定（存 scope 引用）
- EX面: 贤者决定继续 → 新增参与者 + 烈度继续增长

### 4.3 贤者角色

- **观战**: 贤者不可直接干预异变（异变是幻想乡运转的一部分）
- **调停**: 消耗团结度，控制异变不超预期
- **指定解决者**: 消耗10团结，指定"幸运儿"获得：额外调查效率 + 异变影响力 + 特殊事件

### 4.4 EX面（异变结束阶段）

- 贤者议会决定是否让异变继续发展（仅紫 Yukari 触发）
- 新解决者与参与者被指定加入
- 新参与者可能获得额外奖励
- 异变烈度继续增长

### 4.5 赌局

- 每位贤者支持不同目标（预测最终获胜者）
- 异变结束时：预测正确 → 获得额外奖励
- 实现：贤者议会变量存每个贤者押注目标，on_ended 对比

### 4.6 暗中干涉

- 贤者给予特定参与者少量帮助（不改变异变本质）
- 实现：generic action 消耗少量团结度 + 给予buff修正

### 4.7 失控与惩戒触发

- 烈度 > 80 → 失控状态
- 失控 = 异变不再属于正常幻想乡异变，开始威胁秩序本身
- 贤者有权如"非法扩张处理"手段决断 → 衍生为惩戒战争 + 立即停止异变

## 五、惩戒战争与审判系统（Situation + CB + IO敌人，阶段3）

### 5.1 敌意累积

- 私自扩张（使用游戏自带议会而非贤者默许/异变）→ 大量敌意
- 敌意来源：`antagonism_modifier_for_taking_land_from_fellow_member`（现有 0.5）+ 自定义事件
- 敌意超过阈值 → 贤者或阎魔可宣告惩戒战争

### 5.2 双重实现（用户选定：两者结合）

```
【IO敌人机制】add_enemy_to_international_organization = { country = X }
   → 把目标国设为幻想乡IO的敌人，成员自动获得CB，天然支持包围网

【惩戒CB】自定义 casus_belli
   create_enabled = { 敌意阈值 }  declare_enabled = { ... }

【惩戒战争Situation】th_gensokyo_punishment_war_situation
   → 记录罪计数/战争时长/参战国列表/敌意显示
   → 所有满足敌意阈值的幻想乡国家可以加入(维护和平)
   → 参战是获得贡献度的方式之一
```

### 5.3 罪计数（th_gensokyo_crime_var）

| 行为 | 罪值 |
|------|------|
| 屠杀联军军队 | +3~5/场 |
| 拒绝议和请求 | +5/次 |
| 战争持续时间 | +1/月 |

> 局势存在期间持续可见。

### 5.4 阎魔审判 Situation

目标国落败 → 阎魔最后审判：
- 仅赔款/破产
- 放弃非法扩张领土
- 额外削弱国力
- **20-30年沦为彼岸监管国（判刑）**：监管国是宗主无特权的附属国，无法独立处理任何事物，刑满释放为独立国家
- 宣判结束后 → 获得更多幻想乡团结度

### 5.5 审判法律（三级）

| 法律 | 等级效果 |
|------|----------|
| 劝善（鼓励向善） | 最低从严倾向 / 最短监管时长 / 最少团结度 |
| 有序（维护秩序） | 中等从严倾向 / 中等监管时长 / 中等团结度 |
| 因果必尝（报应） | 最高从严倾向 / 最长监管时长 / 最多团结度 |

> 随等级升高 → 阎魔审判从严倾向↑ + 监管国家时长↑ + 团结度获取↑

### 5.6 监管国 Subject

```
th_gensokyo_supervised_state = {
    has_limited_diplomacy = yes
    can_be_annexed = no
    allow_declaring_wars = { always = no }
    has_overlords_ruler = no
    # 刑满自动释放(on_disable / 定时解除)
}
```

### 5.7 目标国胜出

目标国击败阎魔及惩戒战争 → 在局势存在期间：
- 获得特殊行动
- 获得宣称领土
- 可进行多场扩张

## 六、幻想乡守护与时代（阶段4）

### 6.1 时代补全

当前仅 `age_1_traditions` + `age_2_renaissance`，需补时代3/4（对应"第四时代解锁守护"）。

### 6.2 守护席位（th_gensokyo_io_guardian_special_status）

- 第四时代解锁（advance 时代门槛）
- 4-5-6时代作为幻想乡统一进程主导
- 根据法律不同可从 1-5 席
- 要求：未接受过审判 + 当前恶名低 + 与贤者关系良好
- 由贡献和权重按顺序推举产生（对标灵梦/早苗）
- 拥有特殊行动，类似幻想乡特殊列强
- 统一鼓励时代获得更多整合便利

### 6.3 贤者/阎魔的反统一立场

- 贤者和阎魔始终维护幻想乡的稳定、破碎与传统
- 守护席位统一进程 vs 贤者传统守序 → 机制性张力（事件/修正冲突）

## 九、遗留问题与待平衡项

1. 贡献度→影响力换算率（建议1:1，需实测平衡）
