### ============================================================
### 弹幕战系统 — 集中数值（平衡调整入口）
### 弹幕火力水平（th_danmaku_firepower_value）=
###   基础 10 + 统治者军事×10 + 正统信仰容忍×100 + 稳定度×2
###   + 弹幕火力值（平加修正） × (1 + 弹幕火力值修正%)
### 全部数值为初值，标注待调；遭遇战/对决战 事件与效果均引用本文件键
### ============================================================

### ------------------------------------------------------------
### 弹幕火力水平（核心公式，国家 scope 读取）
### 分量已验证：ruler_or_regent.mil（flavor_BYZ.txt:2454）、
###   modifier:tolerance_own（00_modifier_types.txt:6976 country 类）、
###   stability（脚本值裸引用，red_turban_rebellions.txt:3433 先例，范围约 -100~100）、
###   modifier:th_danmaku_firepower_*（本模组自定义，见 modifier_type_definitions）
### 2026-08-28 定案：军事×10（100 军事 ≈ 1000）、容忍×100、稳定×2
### ------------------------------------------------------------
th_danmaku_firepower_value = {
    value = 10                                  # 基础值（待调）
    add = {
        value = ruler_or_regent.mil
        multiply = 10                           # 每 1 军事能力 = 10 火力
    }
    add = {
        value = modifier:tolerance_own
        multiply = 100                          # 每 1 正统信仰容忍 = 100 火力
    }
    add = {
        value = stability
        multiply = 2                            # 每 1 稳定度 = 2 火力
    }
    add = modifier:th_danmaku_firepower_base_modifier   # 弹幕火力值（平加；advance/事件/异变累加）
    multiply = {
        value = 1
        add = modifier:th_danmaku_firepower_modifier    # 弹幕火力值修正（百分比）
    }
}
