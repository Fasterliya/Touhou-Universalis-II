### 公式 = 经济基础 + 预留异变贡献值 + 人口归一化（分量系数独立可调）
### 用途: 议会投票权重（special_status_power 动态公式引用）——
###       th_gensokyo_io_vote_power_value = 影响力 × (1 + 幻想乡影响力修正)
###       （修正来自价值观条 left/right modifier：缘 +50% / 乱 -50%，渐进式）
### 数值为初值「待调」：实测权重分布后调系数（人口归一化 100000 与税基权重）
### 2026-08-21 实测修复：country_tax_base 是引擎硬编码 script value
###   （base game hre_action_values.txt:6 直接 value = country_tax_base 引用），
###   不是 modifier 字段——原 modifier: 前缀读取为空 → 影响力恒 0 →
###   combined_special_status_power = 0 → 议会投票权重 0（投了没票）
### ============================================================
th_gensokyo_io_influence_value = {
    value = country_tax_base                # 经济基础（引擎 script value，裸引用）
    ### 2026-08-23 实测修复：var: 裸引用在变量未设置时（旧档/后加入成员）
    ### 导致整个 script value 返回 none 类型 → special_status_power 失效 →
    ### 议会投票权重异常（game.log "Value of wrong type ... Got value of type
    ### 'none'" at th_gensokyo_io.txt:31/201 + "Failed to fetch variable" 刷屏实证）。
    ### 守卫包装（维基 Variable:898 / 反模式 142 同款）：变量存在才加，缺失按 0
    if = {
        limit = {
            has_variable = th_gensokyo_personal_contribution_var
        }
        add = var:th_gensokyo_personal_contribution_var   # 预留的异变贡献值（现有变量）
    }
    add = {
        value = total_population             # 人口（total_population 实证：diplomatic_values.txt:132）
        divide = 100000
    }
}

### 投票权重 = 影响力 × (1 + 影响力修正)
### modifier:th_gensokyo_io_influence_modifier 读取自定义修正字段
### （modifier: 读取实证：union.txt:110 / hre_action_values.txt:84；字段定义见
###  modifier_type_definitions/th_gensokyo_societal_value_modifiers.txt 双目录）

    value = th_gensokyo_io_influence_value

        value = th_gensokyo_io_influence_value
        multiply = modifier:th_gensokyo_io_influence_modifier
    }
