### 全局基线：所有 AI 统一先加"征服本地区（较弱）"与"默认不殖民外部世界"
### 2026-08-29 作者注释掉 is_ai 过滤（提交 949edca）——保持禁用，勿随意恢复：
### 多人游戏开局评估 is_ai/is_human 不稳（EU5 wiki 同款警告，开局玩家分配未完成）。
### 对人类国家加 AI 地区偏好是惰性的（人类不使用 AI 扩张逻辑，仅托管时生效），
### 无功能损失；如需严格 AI-only，应改到首次 monthly_country_pulse（玩家分配已稳定）。
th_apply_generic_area_preferences_effect = {
	every_country = {
		# limit = {
		# 	is_ai = yes
		# }
		add_area_preference = th_generic_conquer_home_region
		add_area_preference = th_avoid_outer_world_colonization
	}
}
