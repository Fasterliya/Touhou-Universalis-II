### 第 1 档 · 谴责（carrier = 逐成员 effect，**无 modifier 字段**）
### 语义：全体幻想乡 IO 成员对**被诉国**产生敌意 + 好感惩罚（外交孤立）
### EU5 没有"被所有人讨厌"的聚合字段（R2 §R2-1(a)：全表 13 个 antagonism_* 字段
### 逐对国家、有方向）→ 必须逐成员施加，方向 = root → target
###   （方向实锤三处：VANILLA\common\on_action\country_yearly.txt:931-933 注释 +
###    :947-950；country_interactions/break_others_alliance.txt:80-91；
###    on_action/_hardcoded.txt:4313-4321）
### 【一次性 vs 每月】**一次性施加**：base game 全部 4 处脚本
###   add_antagonism 用法（country_yearly.txt:947、_hardcoded.txt:4317、
###   break_others_alliance.txt:81/87、destroy_autocephalous_patriarchate.txt:61）
###   **均不写时长字段**，衰减由 bias 自身的 yearly_decay 承担
###   （VANILLA\common\biases\05_antagonism_hardcoded.txt:5-8：
###    value = 1 / yearly_decay = 2）。另有 add_antagonism_no_duration 存在
###   （effect_localization/country_effects.txt:926）但 base game 0 处使用
###   → 本档按"一次性 + 自然衰减"实现，**不每月重刷**
### bias 键：**T2-2b 已换成专用键**（本档专属，见
### common/biases/th_gensokyo_tribunal_biases.txt）：
###   敌意 th_antagonism_sanction_condemn（value 50 / yearly_decay 10）
###   好感 th_opinion_sanction_condemn（value -50 / yearly_decay 10）
### 换键的两个理由（T2-2a 留下的缺陷，登记在新 static_modifiers 文件尾部）：
###   ① 原复用键语义不符；② 原复用键不能精准撤销（remove_* 按键整体移除）。
### 换键后，本档撤销可在 *_remove_effect 里逐成员精准 remove_antagonism /
### remove_opinion（见下方第 1 档撤销段）。

### 第 1 档撤销：**T2-2b 起逐成员精准撤销**
### 原理：remove_antagonism / remove_opinion 是**按 bias 键整体移除**——
###   蓝本 VANILLA\common\peace_treaties\scaligeri_peace_treaties.txt:36-39
###   （`remove_antagonism = { target = scope:winner modifier = <bias> }`，
###    在 every_known_country 体内执行 ⇒ 每个国家移除自己对 winner 的该键敌意）
### 为什么现在能撤：T2-2b 已把第 1 档换成**专用键**
###   th_antagonism_sanction_condemn / th_opinion_sanction_condemn，
###   整体移除只会命中本法施加的那一层，不会误伤别的合法敌意记录
###   （这正是 T2-2a 当初"只摘标记、靠自然衰减"的原因，现已解除）
### 方向：与 add_* 一致（当前 scope 的成员 → target = 被诉国）
### effect_localization 存在性：remove_antagonism
###   VANILLA\common\effect_localization\country_effects.txt:942、
###   remove_opinion 同文件 :850
### remove_opinion 用法蓝本另有 events/situations/italian_wars.txt:1444-1445
###   （双向成对移除）
th_gensokyo_tribunal_tier_1_remove_effect = {
    every_country = {
        limit = { has_variable = th_gensokyo_tarnish_mark }
        save_scope_as = th_tribunal_accused
    }
    scope:th_tribunal_accused ?= {
        ### 须在摘 tarnish 之前调用（本效果靠 tarnish 自我定位被诉国）
        international_organization:th_gensokyo_io = {
            every_international_organization_member = {
                limit = {
                    NOT = { this = scope:th_tribunal_accused }
                }
                remove_antagonism = {
                    target = scope:th_tribunal_accused
                    modifier = th_antagonism_sanction_condemn
                }
                remove_opinion = {
                    target = scope:th_tribunal_accused
                    modifier = th_opinion_sanction_condemn
                }
            }
        }
        if = {
            limit = { has_variable = th_gensokyo_tier_1_mark }
            remove_variable = th_gensokyo_tier_1_mark
        }
    }
}

### 【载体选择：**每月减法**，不用 timed variable】
### 理由（本窗 §3.2 的二选一）：
###   timed variable（set_variable = { name = X months = N }）虽然能省掉每月减法，
###   但它的 value 在存续期内**恒定不变**（只能存一个初始值，不会递减），
###   ⇒ UI 侧"观察期剩余月数"倒计时会一直显示 N，等于没有倒计时。
###   本项目案卷区（T2-5）明确要显示剩余月数（《脚本规格》§2.1 表的
###   "th_gensokyo_observation_months ... 读取点：悔改判定、**UI 倒计时**"），
###   故必须保留一个**活的数值**。
### 代价可控：门控是最廉价的两个 has_variable（见 on_action 的 trigger），
###   全世界绝大多数国家一次哈希查空即返回，真正执行减法的只有
###   持「祟」的极少数国家（同一时刻最多一案一国）。
###
### 幂等性：归零当月调用一次悔改判定后，
###   ① 悔改成立 → 案件结案（tarnish 被摘）⇒ 次月 on_action trigger 即为假；
###   ② 未悔改   → 打 th_gensokyo_observation_done，
###                此后 var > 0 恒假 ⇒ 不再重复判定，直到升档把观察期重置为 6。
### ============================================================

###   承担（旧 parliament_issues/th_gensokyo_trial_issue.txt:34-39 与 :68-73）。

###   judge_core 尾部会 `remove_variable = th_gensokyo_sentence_tier`
###   （crusade_effects.txt:273），tier 一旦被清就无从计算偏离量。
###   同理 baseline / 意向标记也在本步读完后才清。
###
### 【偏离量算法（本窗拍板，见报告 §9）】
###   漂移 = 实判档 − 基准档（阎魔相对"公式档"挪了几格）
###   偏离量 = |漂移 − 意向向量|，意向向量 = 从重 +1 / 从轻 −1 / 无意向 0
###   ⇒ 等价于 |实判档 − 意向档|，意向档 = 基准档 + 意向向量
###   代价 = 偏离量 × th_verdict_deviation_unity_cost_value（每次调用单价）
###   为什么不直接拿"实判档 vs 基准档"当偏离量：那样在"阎魔顺从民意"
###   （意向从重、判基准+1）时反而会被罚 —— 罚错了对象。
###   意向才是"民意"，偏离的参照系必须是意向档。
###   无意向（议会未辩或辩论未产生意向）时意向向量 = 0 ⇒ 任何偏离基准
###   都要付钱，对应《设计定案》§5.5 的"专断的价签"。

### ⑬-前置 · 越权代价（2026-10-04 闭环改造③：裁决事件版）
###   用途：裁决事件的四个 option 各调一次，传入本档档位 $value$（0/1/2/3）；
###         若 |本档 − 基准档| ≥ 2（超出「基准 ±1」的裁量范围）⇒ 额外扣一次团结度。
###   额度 = 复用既有的 th_verdict_deviation_unity_cost_value
###     （用户 2026-10-04 拍板：「等于再偏一档」，零新增数值键）
###   ★ 时序：必须在 th_gensokyo_verdict_apply_effect **之前**调 ——
###     后者末尾会 remove_variable th_gensokyo_sentence_baseline，之后无从比较。
###   写法与下面 ③ 段（偏离意向）同构：temp 变量做差 → 取绝对值 → 阈值判断。
###   团结度接口：th_gensokyo_unity_subtract_effect（th_gensokyo_unity_effects.txt:18，
###     $value$ 参数、clamp 0-100，必须 IO scope 调用）

th_gensokyo_verdict_defiance_effect = {
    every_country = {
        limit = {
            has_variable = th_gensokyo_crusade_target_mark
            has_variable = th_gensokyo_sentence_baseline
        }
        set_variable = {
            name = th_gensokyo_temp_defiance
            value = var:th_gensokyo_sentence_baseline
        }
        change_variable = {
            name = th_gensokyo_temp_defiance
            subtract = $value$
        }
        if = {
            limit = { var:th_gensokyo_temp_defiance < 0 }
            change_variable = {
                name = th_gensokyo_temp_defiance
                multiply = -1
            }
        }
        if = {
            limit = { var:th_gensokyo_temp_defiance >= 2 }
            international_organization:th_gensokyo_io = {
                th_gensokyo_unity_subtract_effect = {
                    value = th_verdict_deviation_unity_cost_value
                }
            }
        }
        remove_variable = th_gensokyo_temp_defiance
    }
}

th_gensokyo_verdict_apply_effect = {
    ### ---------------- ① 目标标记转换 ----------------
    every_country = {
        limit = { has_variable = th_gensokyo_crusade_target_mark }
        set_variable = th_gensokyo_trial_target_mark
    }
    ### ---------------- ② 已宣判标记 ----------------
    ### （宣判四行动的 potential 靠它失效 ⇒ 不需要 cooldown；
    ###  超时兜底的 on_action trigger 也靠它关闭）
    every_country = {
        limit = { has_variable = th_gensokyo_trial_target_mark }
        set_variable = th_gensokyo_verdict_done
    }
    ### ---------------- ③ 偏离意向 → 团结度代价 ----------------
    every_country = {
        limit = { has_variable = th_gensokyo_trial_target_mark }
        save_scope_as = th_verdict_accused
    }
    scope:th_verdict_accused ?= {
        ### 读 tier / baseline 前 has_variable 守卫（铁律 11）：两者都由本窗写，
        ### 但旧档 / 异常态下可能缺失，缺了就整段跳过（不罚也不报类型错）
        if = {
            limit = {
                has_variable = th_gensokyo_sentence_tier
                has_variable = th_gensokyo_sentence_baseline
            }
            ### 漂移 = 实判档 − 基准档
            set_variable = {
                name = th_gensokyo_temp_verdict_drift
                value = var:th_gensokyo_sentence_tier
            }
            change_variable = {
                name = th_gensokyo_temp_verdict_drift
                subtract = var:th_gensokyo_sentence_baseline
            }
            ### 再减去意向向量（从重 = +1 ⇒ 意向档 = 基准 + 1）
            if = {
                limit = { has_variable = th_gensokyo_intent_harsh }
                change_variable = {
                    name = th_gensokyo_temp_verdict_drift
                    subtract = 1
                }
            }
            else_if = {
                limit = { has_variable = th_gensokyo_intent_soft }
                change_variable = {
                    name = th_gensokyo_temp_verdict_drift
                    add = 1
                }
            }
            ### 取绝对值（偏离量只关心大小）
            ### change_variable + multiply = -1 蓝本：
            ###   VANILLA\common\scripted_effects\global_effects.txt:137/141
            ###   （change_variable = { name = value_1_comperator multiply = -1 }）
            ### 负数比较蓝本：VANILLA\common\…\country.txt:701 `karma < -33`、
            ###   :898 `self_control < -10`
            if = {
                limit = { var:th_gensokyo_temp_verdict_drift < 0 }
                change_variable = {
                    name = th_gensokyo_temp_verdict_drift
                    multiply = -1
                }
            }
            ### 偏离 1 档罚一次、2 档再罚一次（上限 2 档：
            ### allow 已把实判档夹在基准 ±1、意向档也在基准 ±1 内）
            ### 单价经统一接口施加（IO scope + $value$ 宏，传入的脚本值本身
            ### 与 scope 无关，故在被调用效果内求值安全）
            if = {
                limit = { var:th_gensokyo_temp_verdict_drift >= 1 }
                international_organization:th_gensokyo_io = {
                    th_gensokyo_unity_subtract_effect = {
                        value = th_verdict_deviation_unity_cost_value
                    }
                }
            }
            if = {
                limit = { var:th_gensokyo_temp_verdict_drift >= 2 }
                international_organization:th_gensokyo_io = {
                    th_gensokyo_unity_subtract_effect = {
                        value = th_verdict_deviation_unity_cost_value
                    }
                }
            }
            remove_variable = th_gensokyo_temp_verdict_drift
        }
        ### ---------------- ⑥ 清 baseline / intent / overdue ----------------
        ### （须在 ⑤ cleanup 摘掉 crusade_target_mark 之前完成 —— cleanup 之后
        ###   本效果再也定位不到被诉国）
        ### **故意不清 th_gensokyo_verdict_done**：它是"本案已判"的常驻标记，
        ### 由下一次战争结束的 ⑫ 清理（《脚本规格》§10.2 的 ⑥ 亦未列它）
        if = {
            limit = { has_variable = th_gensokyo_sentence_baseline }
            remove_variable = th_gensokyo_sentence_baseline
        }
        if = {
            limit = { has_variable = th_gensokyo_intent_harsh }
            remove_variable = th_gensokyo_intent_harsh
        }
        if = {
            limit = { has_variable = th_gensokyo_intent_soft }
            remove_variable = th_gensokyo_intent_soft
        }
        if = {
            limit = { has_variable = th_gensokyo_verdict_overdue }
            remove_variable = th_gensokyo_verdict_overdue
        }
    }
    ### 诸国意向的 IO 变量（存审判庭 —— 《脚本规格》§10.1 指定该 IO；
    ### 审判庭随即被 ⑤ 销毁，此处只是"先清干净"）
    international_organization:th_gensokyo_tribunal = {
        if = {
            limit = { has_variable = th_gensokyo_verdict_intent }
            remove_variable = th_gensokyo_verdict_intent
        }
    }
    ### ---------------- ④ 判决落地（现有核心，勿改）----------------
    ### 内部自己按 th_gensokyo_trial_target_mark 重定位目标与阎魔，
    ### 并读 scope:crusade_target.var:th_gensokyo_sentence_tier
    ###
    ### 【为什么 ④⑤ 必须整段套一个守卫（T2-5 新增的防御，不是风格问题）】
    ###   judge_core 的头部是
    ###     every_country = { limit = { has_variable = th_gensokyo_trial_target_mark }
    ###                       save_scope_as = crusade_target }
    ###   紧接着就是**无 exists 守卫**的 `scope:crusade_target = { … }`
    ###   （crusade_effects.txt:165，现有代码，本窗不改）。
    ###   若本效果被**第二次**调用 —— 同一 tick 内 AI 连点两个宣判档、
    ###   或"超时兜底"与"手动宣判"撞月 —— 此时标记已被第一次的 ⑤ cleanup
    ###   摘掉，那句 scope 引用就会带着未定义的目标进入，
    ###   刷 "Undefined event target 'crusade_target'"（本项目 P1-12 记录过的同类报错）。
    ###   故在调用前确认"被诉国 + 本档 tier"都还在；不在就整段跳过。
    ###   正常路径（首次宣判）两者必然都在 ⇒ 行为不变。
    if = {
        limit = {
            any_country = {
                has_variable = th_gensokyo_trial_target_mark
                has_variable = th_gensokyo_sentence_tier
            }
        }
        ### ---------------- ④ 判决落地（现有核心，勿改）----------------
        th_gensokyo_trial_judge_core_effect = yes
        ### ---------------- ⑤ 清理（现有）----------------
        ### 清 crusade_target_mark / trial_target_mark / crusade_participant
        ### + 解散审判庭
        th_gensokyo_trial_cleanup_effect = yes
    }
}

### ⑭ 超时兜底脉冲体（T2-5 新增）—— "战后 6 个月阎魔仍未宣判 → 自动按诸国意向判决"
### 调用点（**唯一**）：on_action/th_gensokyo_tribunal_pulse.txt 的
###   th_gensokyo_tribunal_overdue_pulse
### 前置（由该 on_action 的 trigger 保证，故此处不再全局自定位）：
###   当前 scope = 被诉国，且 has_variable = th_gensokyo_crusade_target_mark
###   与 has_variable = th_gensokyo_verdict_overdue 均为真，
###   且 has_variable = th_gensokyo_verdict_done 为假
###
### 【载体：每月减法，不用 timed variable】
###   理由同 ④ 观察期脉冲体（本文件 :439-449）：timed variable 的 value
###   在存续期内恒定不变，做不了"剩余月数"倒计时（UI 要显示它）。
###
### 【自动档 = 意向档（不是"基准 ±1 里的某一档"）】
###   意向档 = 基准档 + 意向向量：
###     从重（th_gensokyo_intent_harsh）→ 基准 + 1（基准 = 3 时封顶 3）
###     从轻（th_gensokyo_intent_soft） → 基准 − 1（基准 = 1 时封底 0）
###     无意向                        → 基准档本身
###   与《设计定案》§5.5"自动按诸国意向判决"逐字对应。
###   附带效果：自动判决恰为意向档 ⇒ ⑬ 算出的偏离量恒为 0 ⇒
###   "超时"这件事本身不额外扣团结度（阎魔的代价是失去定谳权，不是再挨罚）。
###
### 【幂等】归零当月调用 ⑬，⑬ 会打 verdict_done 并清 verdict_overdue
###   ⇒ 次月 on_action trigger 即为假。
### ============================================================
th_gensokyo_tribunal_verdict_overdue_effect = {
    if = {
        limit = { var:th_gensokyo_verdict_overdue > 0 }
        change_variable = {
            name = th_gensokyo_verdict_overdue
            subtract = 1
        }
        ### 减到 0 的**当月**立即自动宣判
        ### （用 NOT { > 0 } 而非 = 0：数值相等的比较式无蓝本先例，不等式有 ——
        ###  同本文件观察期脉冲体的口径）
        if = {
            limit = {
                NOT = { var:th_gensokyo_verdict_overdue > 0 }
                has_variable = th_gensokyo_sentence_baseline
            }
            ### 先落"意向档"到 th_gensokyo_sentence_tier（⑬ 只负责按 tier 落地）
            set_variable = {
                name = th_gensokyo_sentence_tier
                value = var:th_gensokyo_sentence_baseline
            }
            if = {
                limit = { has_variable = th_gensokyo_intent_harsh }
                ### 从重：基准 + 1，基准 3 封顶（裸 if 判上界，不用 min/max 块）
                if = {
                    limit = { NOT = { var:th_gensokyo_sentence_baseline >= 3 } }
                    change_variable = {
                        name = th_gensokyo_sentence_tier
                        add = 1
                    }
                }
            }
            else_if = {
                limit = { has_variable = th_gensokyo_intent_soft }
                ### 从轻：基准 − 1，基准 1 时落到 0 档（赔款破产；0 档在 judge_core
                ### 里有完整的落地分支，故封底 0 而不是 1）
                change_variable = {
                    name = th_gensokyo_sentence_tier
                    subtract = 1
                }
            }
            ### 与宣判四行动走**同一个**落地口
            th_gensokyo_verdict_apply_effect = yes
        }
    }
}

### ⑮ 【2026-10-01 T2-5b】圣战「大义」—— 施加 / 移除
### 语义：《设计定案》§7「宣战时全体参与者获『大义』临时修正（士气 / 人力 / 威望）」
### 载体：static_modifiers/th_gensokyo_tribunal_crusade_modifiers.txt 的
###       th_gensokyo_grand_cause_modifier
### 数值：script_values/th_gensokyo_io_chain_values.txt 的 T2-5b 段

### 【"参与者"如何确定 —— 本窗的判断与依据】
###   取 **宣战那一刻的审判庭成员**（不是"参战方全体"）：
###   ① 审判庭 IO 定义 join_offensive_wars_always（international_organizations/
###      th_gensokyo_tribunal.txt:103-107）= 成员对"持 crusade_target_mark 的
###      敌国"自动入战 ⇒ 成员集合 ≡ 实际入战集合（引擎在宣战当帧驱动）。

###   ③ 后来加入的义兵（generic_actions/th_gensokyo_join_crusade.txt）走

###      且 join_crusade 已给 +5 贡献作为对价。
###      ⇒ 后果：中途加入者拿不到大义（其加成从入庭那一刻的下一场宣战起才有）。
###
### 【遍历写法】international_organization:<IO> = { every_international_organization_member }
###   —— base game 直用先例：situations/guelphs_and_ghibellines.txt:311
###      （international_organization:guelphs_io ?= { every_international_organization_member = { ... } }）；
###      本项目同族先例：on_action/th_gensokyo_chain_events.txt:663/674/692/707。
###   ※ 铁律 6 的教训只针对 **ai_will_do（trigger 上下文）** 里的
###     any_international_organization_member（scope 不匹配实测报错）；
###     本处是 **effect 上下文**，且用 every_* 全遍历 —— 与教训不冲突。

th_gensokyo_tribunal_grand_cause_apply_effect = {
    ### ?= 守卫：唯一 IO 可能已被解散（工具提示预演 / 重复点击的边角态）
    international_organization:th_gensokyo_tribunal ?= {
        every_international_organization_member = {
            limit = {
                ### 被诉国不获大义（它是被告，不是执法者）。
                ### 成员集合按 can_join_trigger 本就排除目标，这里显式再判一次：
                ### 防"开庭时目标标记写入失败 → 被诉国混进成员集合"的配置漂移。
                NOT = { has_variable = th_gensokyo_crusade_target_mark }
            }
            add_country_modifier = {
                modifier = th_gensokyo_grand_cause_modifier
                ### years = -1 = 永久（wiki Modifier_modding §Add modifier parameters：
                ### "If the duration evaluates to -1, the modifier will be permanent"），
                ### 由本文件 ⑮ 的 remove 与战争结束钩子显式移除。
                ### 不用限期（years = N）的理由：战争长度不可预知，限期会在
                ### 战争尚未结束时自然到期（大义中途消失），而永久 + 双出口显式移除
                ### 可保证"战争在则大义在、战争结束则必摘"。
                ### 同项目先例：本文件 ③ 段的第 4 档修正（:432-437）years = -1。
                years = -1
                ### mode = replace = 同名重复施加时"移除后按新时长重挂"（不叠加）。
                ### 幂等依据（wiki 同上 §Add modifier parameters 的 mode 表）：
                ###   replace = "Removes the modifier and reapplies it for the whole
                ###   duration provided"；base game 用例：
                ###   parliament_issues/10_hre_issues.txt:237（years = 3 mode = replace）
                ###   —— 同一 HRE 议题反复通过不会叠出多份。
                ### 本项目第 4 档未写 mode（默认 = extend），故此处显式写明，
                ### 避免"重复宣战叠出多份大义"。
                mode = replace
            }
        }
    }
}

### ⑯ 【2026-10-01 T2-5b】「祟」的可见载体 —— 施加 / 移除
