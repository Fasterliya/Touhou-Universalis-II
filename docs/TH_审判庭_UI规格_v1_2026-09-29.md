## 1. 现状与前置工程

### 1.1 现状（已核实）

| 事实 | 证据 |
|---|---|
| 审判庭**没有任何专属 UI** | `in_game/gui/panels/organization/th_gensokyo_io.gui`（186 行）**整份被注释掉** |
| 实际生效的是贤者议会面板 | `in_game/gui/panels/organization/th_sages_council_io.gui`（367 行） |
| 该面板**整份替换 `organization_panel`**，且**未按 IO 类型分流** | 同上，文件顶层即 `organization_panel = { blockoverride "panel_content" { ... } }`，无类型判定 |
| 内容**无条件渲染** | 三贤者立绘硬编码 `GetCountry('T13'/'T05'/'T83')`（约 231-242 行）、`th_sages_prestige_var` tooltip（约 106-126 行）、团结度饼图（约 139-155 行）、插画 `international_organization_types/th_sages_council_io.dds`（约 221 行） |
| 审判庭唯一的 UI = 底部行动按钮列表 | 同上，约 295-332 行：`datamodel = "[InternationalOrganizationsView.GetActions]"` |

**推论（v1.8 已按蓝本改写，2026-10-01）**：~~点开审判庭看到的应该是贤者议会那一套~~ —— **该推论已被蓝本证据推翻**。

vanilla 的 IO 面板机制是 **`gui/panels/organization/<IO 类型 key>.gui` 一类型一文件**：`theme_templates.gui:1-6` 声明三个 theme 类型（`organization_geodiplomatic_theme` / `organization_religious_theme` / `organization_war_theme`，均 `= organization_panel {}`），各类型文件实例化其中之一并做**点状 `blockoverride`**；`situation\readme.txt` 与 `disaster\readme.txt` 把这条命名约定写成了 PDS 明文（"create a new file … **with the name of the** situation/disaster"）；base game 34 个 IO 类型中 32 个有同名文件（仅 `foreign_league_balkan`、`sikhism` 无 → 用默认面板）。

因此 `th_sages_council_io.gui` 的文件名正好等于贤者议会类型 key，**它只作用于贤者议会**。四条 IO 的实测现状：

| IO | 同名面板文件 | 实际生效面板 |
|---|---|---|
| `th_sages_council_io` | 有（367 行，含唯一一处整份 `panel_content` 替换） | 它自己那份 |
| `th_gensokyo_io` | 有但 177/186 行被注释 | **vanilla 默认面板** |
| `th_gensokyo_tribunal` | **无** | vanilla 默认面板 |
| `th_human_village_io` | **无** | vanilla 默认面板 |

> **实机确认步骤（30 秒，仍未跑）**：创建审判庭 → 点开 → 若显示的是 **vanilla 默认 IO 面板**（而非 T13/T05/T83 立绘 + 贤者威望），即证实"一类型一文件"。**当前按该假设推进**（用户 2026-10-01 拍板）；若实机否定，退路 = `EqualTo_string(InternationalOrganizationsView.GetInternationalOrganization.GetType.GetNameKey,'<类型key>')` 做 `visible` 判定（vanilla 先例：`government_tooltips.gui:316`、`common.gui:177/185/199/345/535`）。

### 1.2 前置工程：给审判庭建**同名面板文件**【v1.8 改写，2026-10-01】

**目标**：审判庭有自己的面板；**不需要造任何"分流机制"**（原方案 A/B/C 全部作废）。

**机制（已回蓝本核实）**：`gui/panels/organization/<IO 类型 key>.gui` 即该 IO 的面板文件，文件内实例化一个 theme 类型并点状 `blockoverride`。

| IO | 要做什么 |
|---|---|
| 幻想乡 IO | 走 vanilla 默认面板（现状成立）；**唯一改动**是补一行宝库分页 override（见 §5 与《脚本规格》§10.7） |
| 贤者议会 IO | 现状那份继续生效，**与审判庭无关、本轮不动**（是否改成点状覆盖是它自己的独立议题） |
| 审判庭 IO | **新建 `gui/panels/organization/th_gensokyo_tribunal.gui`**（本系统的 UI 主战场） |
| 人间之里 IO | 走默认面板；既有债务：`th_human_village_io` 的 `_desc` loc 四语全缺（`io_tooltips.gui:477` 的 `Concatenate(GetNameKey,'_desc')` 会渲染为空） |

**新面板文件的写法蓝本**（二选一，均 vanilla 在跑）：
- 照 `hre.gui:1` 的 `organization_panel = { blockoverride "..." { ... } }`（直接实例化基类型）；
- 或照 `ilkhanate.gui:1` / `middle_kingdom.gui:1` 的 `organization_geodiplomatic_theme = { ... }`（实例化 theme 类型）。

> **【已解除的阻塞】** 原 v1 的【待验证 1】"A 与 B 的可行性 / 不落地则 UI 全部白做"**不再成立**：本题已由 R1 批回蓝本核实（报告 `TH_审判庭_待验证结论_R1_UI_v1_2026-10-01.md` §R1-1）。
> **残留不确定性**：该命名约定**没有 PDS 明文**（依据 = 同类系统 readme 成文约定 + 命名 1:1 + 合并假设不成立，三重推理）。实机验证列在 T1 完成后的验收清单。

### 2.1 关系图规格

| 段 | 显示 | 数据源 | 状态变化 |
|---|---|---|---|
| 左 · 彼岸 | 彼岸旗 + 阎魔国徽 + 「是非曲直厅」 | 固定（阎魔 = 幻想乡 IO `leader_country`，tag T25） | 固定，不随案情变化 |
| 中 · 世俗代理人 | **单面大国旗** + 国名 + 「最近强国 · 领衔」 | 持 `th_gensokyo_tribunal_agent_mark` 的国家（**独立标记**；审判庭 IO 领袖是阎魔，不代表代理人） | 升档点名 / 改派 / 开庭时更新 |
| 中下 · 随征 | 「随征 N 国」+ 小旗排（≤8 面，超出显示 `(+N)`） | 审判庭 IO 成员遍历，剔除代理人 | 成员加入 / 退出实时更新；**三贤者在列，故永不为空** |
| 右 · 罪人国家 | 国旗 + 国名 + 「乱 XX · 罪 XX」 | 持 `th_gensokyo_crusade_target_mark` 的国家 + `th_gensokyo_sin_var` | 立案时出现；结案后转灰保留（T3） |
| 箭头 | 静态贴图，方向 彼岸 → 代理人 → 罪人 | — | — |

**三条硬要求：**

1. **中段那面旗是开关，不是装饰。** 若采纳「代理人领衔制」（见《设计定案》第 11 章 A），制裁能否升档直接取决于它是否接受 —— UI 上要能看出来（例如它未接受时显示灰色 + 文案"代理人拒绝领衔"，并给出「改派」入口）。
2. **数据全活。** 三段都必须是活数据，不做贴图拼贴；出问题时要能一眼看出是哪一段没数据。
3. **可点击（T3）**：成员旗 → 跳国家；罪人旗 → 跳被诉国。

### 2.2 行动区规格

- 沿用现有机制：`datamodel = "[InternationalOrganizationsView.GetActions]"` 自动列出所有 `type = internationalorganization` 且 `potential/allow` 通过的 GenericAction，**零 GUI 改动即可加按钮**。
- **分组显示**：T1 用**文案前缀**分组 —— 本地化名写成 `【彼岸】宣战（圣战）` / `【代理人】征召随征国` / `【世俗】退出审判庭`。理由：把列表拆成两个 datamodel 需验证可行性（**待验证 6**），前缀方案零风险且语义到位。
- `show_in_gui_list = no` 可让某些行动只由自定义按钮触发（蓝本 readme 有此字段），留给 T3 的"关系图右键"等交互。

## 5. 元素规格

| 元素 | 数据源 | 状态 |
|---|---|---|
| 彼岸旗 | 静态 + 阎魔国徽 | 固定 |
| 代理人旗 | 持 `th_gensokyo_tribunal_agent_mark` 的国家 | 升档点名时确定；改派或拒绝领衔时更新 |
| 随征旗排 | IO 成员遍历 | 实时；≤8 面，超出 `(+N)` |
| 罪人旗 | `th_gensokyo_crusade_target_mark` | 立案出现，结案转灰 |
| 案卷卡 | 罪名账本 + `th_gensokyo_sin_var` | 每 6 个月刷新履约状态 |
| 制裁阶梯条 | 制裁档位变量 | 生效 / 失效 / 未达成 / 已撤销 |
| **罪业条** | `th_gensokyo_sin_var`（罪）+ `th_gensokyo_attitude_var`（态度）合计 | **单条**，max 100，刻度打在 50 / 75；**刻度随审判法移动**（劝善 40/65、有序 50/75、因果必尝 60/85）；hover 拆开构成 |
| **诸国意向条** | 审判庭议会辩论结果 | "从重 N / 从轻 M"；宣判按钮 tt 内并排显示"依律（基准 X）"与"依民意（意向 Y）" |
| **公库余额** | **引擎原生 IO 宝库**（IO 定义加一行 `gold = yes`，`catholic_church.txt:30`） | **显示在原版 IO 面板的「宝库」分页**（`organization_treasury_tab_visible` + `SUBTAB_IO_TREASURY`，`common.gui:234-252`），**不在审判庭面板**。**v1.8 修正（2026-10-01）**：幻想乡 IO 走的是 vanilla 默认面板，其宝库本体（`organization_panel_treasury_area`，`common.gui:489`）仍在树上，故最小改动 = 在 `th_gensokyo_io.gui` 里**新写一行** `blockoverride "organization_treasury_tab_visible" { visible = yes }` + IO 定义 `gold = yes` + 补 `unlock_contribute_to_organization_treasury`（否则玩家仍捐不了钱；vanilla 该 unlock 只由 HRE 法律给，`20_hre.txt:193/311`）。**不涉及贤者议会面板** |
| 行动区 | `InternationalOrganizationsView.GetActions` | 按 actor 身份过滤 |
| 结案档案 | 判决记录 | 仅展示，不参与计算 |

### 5.2 行动按钮组（第三轮变更）

施压与宣判都用**多个独立行动**，而不是一个会改名的主按钮。原因是硬约束：**GenericAction 的按钮名来自本地化键，是静态的**；而 `select_trigger` 只能选国家 / IO / 地点，**"档位"不是一个可被选择的实体**。

**施压组（四档，阎魔）** —— 未满足门槛的**显示但置灰**，`allow` 的 tt 里写明缺什么（"需观察期结束" / "需有代理人肯领衔"）。这比隐藏更能教会玩家阶梯长什么样。

**宣判组（四档，阎魔）** —— `allow` 限定在**基准 ±1** 内可点。阎魔打开面板看到的是一排"宣判·XX"，只有两个亮着；**那一屏本身就是裁量范围的可视化**。tt 内并排显示"依律（基准 X）"与"依民意（意向 Y）"，让阎魔知道自己正在违背谁。

```
┌─ 宣判 ────────────────────────────────────────┐
│ [ 宣判·赔款破产 ]   置灰（低于裁量下限）      │
│ [ 宣判·归还 ]       ● 可点  依律基准 1        │
│ [ 宣判·削弱 ]       ● 可点  依民意意向 2      │
│ [ 宣判·监管国 ]     置灰（超出裁量上限）      │
└───────────────────────────────────────────────┘
```

### 5.1 hover 规格（四个必须有）

| 悬停对象 | 内容 |
|---|---|
| 罪名条目 | 来源与时间（哪块地 / 哪次战争 / 哪一年）、是否已履约 |
| 制裁档 | 解锁条件、剩余观察期、该档的自伤代价 |
| 罪业条 | 拆解：罪（立案固定）+ 态度（战时累积）的算法、当前刻度由哪一档审判法决定、未履约条目清单 |
| 关系图中段 | 成员名单（随征国全列） |

| 档 | 内容 | 依赖 | 能否立刻开工 |
|---|---|---|---|
| **T1** | ① 面板分流（前置，第一件）② 审判庭面板概览 tab 关系图（彼岸 → 代理人 → 罪人） ③ 行动区（含 `【彼岸】/【代理人】/【世俗】` 前缀）④ 辩论 tab 的「预计档位」一行 ⑤ 空状态「本庭尚未开庭」 | 只显示**已存在的数据**：`crusade_target_mark`、`sin_var`、IO 成员；新增的只有代理人标记的写入 | ✅ 可 |
