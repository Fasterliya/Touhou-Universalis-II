## 四、根因分析

### 根因 1（✅ 已修复）：1.2 defines 与 1.3 引擎不兼容
- 1.2 原版 `loading_screen/common/defines/00_defines.txt`（2332 行）覆盖 base 1.3（2609 行）
- 缺失 277 个新 define（含 `GREAT_POWER_AREA_WEALTH_DIVISOR` 等除数）→ 除零崩溃
- **修复**：删除 1.2 拷贝，新建 `th_defines.txt`（44 个自定义值覆盖集）

### 根因 2（✅ 已修复）：模板引用其他 MOD 的 key
- `th_gensokyo_monarchy.txt:65`：`distribution_of_power_law = dop_favor_the_ruler_miku_ver`
- `dop_favor_the_ruler_miku_ver` 是萌陆风云 ACGV MOD 的 key，base 1.3 无此法律
- 95 国全部 include 此模板 → 97 次 "Failed to read key reference" → AI 外交目标全面失败
- **修复**：改为 base 1.3 合法值 `dop_favor_the_ruler`

### 根因 3（✅ 已修复）：TH 段缩进错位（核心）
- TH 段从 1.2 合并时用 `spaces/3` 转换（6 空格 → 2 tab）
- **base 1.3 国家是 1 tab**（与内层 countries 同级），TH 被转成 2 tab = 深 1 级
- 引擎按 tab 层级识别国家 → 95 国全部未被识别 → capital/government/继承制全部缺失
- **修复**：TH 段整体 tab 减 1（T00-T94 从 2tab → 1tab），括号深度恢复 0

### 根因 4（✅ 已修复）：TH 国家数据错误
| 错误 | 国家 | 修复 |
|------|------|------|
| 领地冲突（同一地块两国声明）| T08/T09、T25/T40、T81/T82 | 地块去重，归属一方 |
| include 模板两次 | T51/T52 | 删除重复 include |
| 首都是他国地块 | T93（th_synthesizer_avenue 属 T03）| 首都改为自身地块 th_crossroads_teahouse |

### 根因 5（⚠️ 未解决）：AI 无效命令 → buffer 崩溃
- TH 国家初始化成功后，**AI 无效命令依旧**（change_trade_capacity ×40 等）
- 触发：AI 第一轮决策 → 大量命令执行失败 → 引擎缓冲溢出 → `Tried to reallocate a pre-allocated buffer` → 崩溃
- **未定位具体触发源**（候选：TH 市场 AI 操作 / 2D Portrait 基因缺失 / TH 文化人口不匹配）
