## 3. 编码铁律（照 `todo/TH_IO_P2_P5_PLAN.md` 第 2 章）

- `.txt` / `.yml` → UTF-8 **BOM**；`main_menu/setup/start/` → **无 BOM**；`.gui` / `.csv` / `.md` → **无 BOM**
- 修饰符数值 ≤ 5 位小数；变量读用 `var:`；`change_variable` 用 `add =` 不用 `value =`
- 带值 modifier 放 `main_menu/common/static_modifiers/`（不放 `modifier_type_definitions`）
- 新 modifier 写前核对 `00_modifier_types.txt`
- 事件必须含 `outcome = ...`
- **新增/修改任何 key 前先查重**（蓝本 + base game + 工作区）
- 涉及 IO scope 跳转须带 `international_organization:` 前缀；`is_member_of_international_organization` 同理
- 存疑语法写前输出 **Verification 行**（Step / path / quote）

## 5. 人工验收清单（T1 完成后）

1. **面板分流**：依次打开 幻想乡 IO / 贤者议会 IO / 审判庭 —— 三者布局不同，审判庭**不得**出现 T13/T05/T83 立绘与「贤者威望」。
2. **开庭**：`tag T25` → 幻想乡 IO 面板 → 纠弹立案 → 审判庭创建成功。
3. **代理人**：持 `th_gensokyo_tribunal_agent_mark` 的国家 = 与被诉国最近的合格强国（距离触发器不可用时退化为实力最强者）；关系图中间那面旗与之相符；**审判庭 IO 领袖仍为阎魔**。
4. **强制参战**：三贤者在审判庭成员列表中；圣战宣战后三贤者出现在战争攻击方。
5. **关系图三段**：右段显示被告国徽 + 乱值；撤掉目标标记后右段消失、关系图不崩。
6. **随征旗排**：手动让一国加入 → 中间小旗排 +1，数字同步；超过 8 面时显示 `(+N)`。
7. **辩论 tab**：辩论进行中，「预计档位」显示与实际判决档位相符。
8. **空状态**：审判庭存在但无案卷时显示「本庭尚未开庭」，不空屏。
9. **日志**：无 `Undefined event target` / `Value of wrong type` / `Scoped object of type 'country' is not valid` 新增刷屏（本次改动不得引入新报错类别）。
