### 1.1 铁律 5 的连带后果（设计层面必须绕开）

`ai_will_do` 读不到变量，意味着 **AI 无法用 `var:th_gensokyo_sanction_tier` 判断"现在第几档"**。绕开方式：

- 每档给被诉国打**独立标记**（`th_gensokyo_tier_1_mark` … `th_gensokyo_tier_4_mark`），`has_variable` 是触发器，`ai_will_do` 可用；
- 或把 AI 需要知道的量写成**独立标记**而非数值（例如 `th_gensokyo_observation_done`）。

本规格采用**独立标记**方案（见第 2 章）。

### 1.2 检索规程（v1.8 新增，2026-10-01）

**"这个触发器 / 效果 / 修正字段到底存不存在"的第一检索入口**，不是 wiki、不是工作区，而是 base game 的三处权威名录：

| 想查什么 | 去哪查 | 路径 |
|---|---|---|
| 触发器是否存在 | `trigger_localization\` | `VANILLA\common\trigger_localization\`（`country_triggers.txt` / `location_triggers.txt` / …） |
| 效果是否存在 | `effect_localization\` | `VANILLA\common\effect_localization\` |
| modifier 字段是否存在 | `00_modifier_types.txt` | **`GAMEROOT\main_menu\common\modifier_type_definitions\`**（注意：**不在** `in_game\common\` 下；本项目自己的定义则放在 `in_game\common\modifier_type_definitions\`，可加载） |

> 依据：R1/R2/R3 三批调研里，"字段不存在"这类结论全部是靠这三处名录定谳的（例：`expand*` 只有 6 个 RGO/水渠字段 → 确认"领土扩张花费"字段不存在；`border_distance_to` 命中 → 确认"最近"可做）。
> **工具纪律**：回蓝本一律用 ripgrep（grep 工具）。**PowerShell 的 `Select-String -Path "...\**\*.gui"` 里 `**` 只匹配一层目录**，会漏掉深层文件（本轮已致一次误判）。

### 4.2 `th_gensokyo_tribunal_escalate` —— 升档（新增）

| 项 | 内容 |
|---|---|
| `potential` | `scope:actor ?= { is_leader_of_international_organization = ...th_gensokyo_io }` |
| `allow` | 存在被诉国且观察期已归零：`custom_tooltip` 包 `any_country = { has_variable = th_gensokyo_tarnish_mark has_variable = th_gensokyo_observation_done }` |
| `select_trigger` ①| 幻想乡 IO（同上） |
| `select_trigger` ②| 被诉国（`interaction_source_list` 过滤 `th_gensokyo_tarnish_mark`） |
| `select_trigger` ③| **代理人点名**：`looking_for_a = country`，`interaction_source_list` = 合格候选列表（第 5 章），`column` 按"是否合格/实力/位置"给出可读信息 |
| `effect` | ① 清旧档标记与修正 → 打新档标记（tier N+1）<br>② 打 `th_gensokyo_tribunal_agent_mark` 到代理人；代理人有变更时同时清旧代理人标记<br>③ 观察期重置为 6、清 `th_gensokyo_observation_done`<br>④ 挂新档修正、移除上一档修正<br>⑤ 代理人同意流程（见下） |
| `cooldown` | `{ type = th_gensokyo_tribunal_escalate months = 3 }` |
| `ai_will_do` | 用 `any_country` + `th_gensokyo_observation_done` 标记判定（不可读变量） |
| 本地化 | `th_gensokyo_tribunal_escalate` / `_desc`、`TH_TRIBUNAL_AGENT_REFUSED` |

**代理人同意流程 —— 实现载体【待验证 2】（2026-10-01 用户拍板"提名 + 征求同意"，路径 A 成为主线）：**

- **路径 A（事件）—— 主线**：`effect` 内给被提名国发事件 `th_gensokyo_tribunal_agent_consent`（`outcome = neutral`，两个 `option`：接受领衔 → 调用升档落地 effect；拒绝领衔 → 打 `th_gensokyo_agent_refused` + 通知阎魔 + 该档暂挂）。**不确定点（现已成为阻塞项）**：EU5 事件 option 的 AI 选择机制（是否需要权重字段、字段名是什么）。
- **路径 B（脚本判定 + 行动）**：`effect` 内直接按 `th_gensokyo_agent_will_accept_trigger` 判定（AI 与国家通用），不满足则当场拒绝并保留原档位；玩家代理人用 `th_gensokyo_tribunal_agent_refuse` 行动事后抗命。
- **退路（必定可行）**：**取消同意流程** —— 提名即落地，被提名国只能事后抗命（声望/贡献损失 + `th_gensokyo_agent_refused`）。功能弱一档但零不确定性。

## 5. 代理人选取规格

**执行位置**：`th_gensokyo_tribunal_escalate` 的 `select_trigger` ③ 的 `interaction_source_list`（玩家阎魔手动点名）；AI 情形由 `ai_will_do` 无法读变量，因此**AI 阎魔的点名顺序由脚本 effect 择优写标记**，AI 只需要判定"要不要升档"。

**合格候选（`limit` 逐条）**：

1. `is_member_of_international_organization = international_organization:th_gensokyo_io`
2. 非被诉国（`NOT = { has_variable = th_gensokyo_tarnish_mark }`）
3. 非被诉国盟友 / 附属 / 宗主（`is_allied_with` / `is_subject_of`，照 `th_gensokyo_crusade_declare.txt:232-248` 的关系判定写法）
4. 非免制裁期（`NOT = { has_variable = th_gensokyo_sanction_immunity }`）
5. 非监管国（`NOT = { is_subject_type = subject_type:th_gensokyo_regulated_state }`，照 `th_gensokyo_chain_events.txt:370` 写法）
6. 非曾拒绝领衔（`NOT = { has_variable = th_gensokyo_agent_refused }`）
7. **硬门槛**：`relative_strength = { target = <被诉国> value >= 1.0 }`（照 `th_gensokyo_crusade_cb.txt` / `join_crusade` 的写法）

**排序（"最近"）——【待验证 5】：**

| 优先级 | 判据 | 可行性 |
|---|---|---|
| 1 | 直接距离触发器（`distance_between` 之类） | 本项目未使用过 → 回蓝本查 |
| 2 | 共同边界（`has_border_with` 之类） | 本项目未使用过 → 回蓝本查 |
| 3 | 首都距离（经 `capital` scope 的距离判定） | 同上 |
| 4 | **兜底：实力最强者** | 现成触发器（`relative_strength` / `great_power_score`）**必定可行** |

> 选取"最近"失败不影响功能闭环 —— 退到第 4 条仍能选出代理人，只是地缘味道变淡。**因此本项不阻塞 T2-4。**

**兜底链**：合格候选中无满足距离者 → 实力最强者 → 仍无 → **三贤者中实力最强者**（三贤者必然参战，永不为空）。

**写入**：`set_variable = th_gensokyo_tribunal_agent_mark`（在国家身上；审判庭 IO 无法持久保存 scope）。

### 10.6 被诉方履约行动组（新增，2026-10-01）

**为什么加**：悔改判定按【履约行为】判（本文档 §6），但被诉方**没有对应按钮** —— 玩家知道要悔改，却不知道能做什么。这是闭环缺口，不是锦上添花。

| 行动 | 对应履约条目 | 关键字段 |
|---|---|---|
| `th_gensokyo_tribunal_fulfill_land`（履约·交还领地） | 已归还非法所得 | `potential`: 被诉国（持 `th_gensokyo_tarnish_mark`）；`select_trigger`: `looking_for_a = location`，候选限定涉案地块（照 `th_gensokyo_feast.txt:80-86` 的选址写法 + `is_owned_by_international_organization` 之类的限定方式）；`effect`: `change_location_owner = previous_owner`（**照 `crusade_effects.txt:140` 的现成写法**）+ 更新履约进度 |
| `th_gensokyo_tribunal_fulfill_pay`（履约·支付赔款） | 已付赔款 | `potential`: 被诉国；`price` / 扣款写法照 `th_gensokyo_feast.txt:88`；`effect`: 累计写 `th_gensokyo_confess_paid`；**入公库**（依赖待验证 9） |
| *（不设行动）停止战争* | 已停止对受害国的战争 | 走现有和约机制；案卷区红字提示"仍在与受害国交战"，**不新增行动** |
| （可选）`th_gensokyo_tribunal_self_sentence`（自请监管） | 自请监管 | 直接把 `th_gensokyo_sentence_tier` 设为 3 并调判决效果，换取免于开庭 —— 最重的止损选项；**本轮可缓** |

**设计关系**：履约 = **分期**（逐条做到，逐步满足悔改条件，便宜但要等 6 个月一档的节奏）；认罪赎罪 = **一次结清**（贵，当场撤销全部制裁）。这两条构成被诉方真正有意义的选择。

**AI 注意**：`ai_will_do` 不可读变量（铁律 5），因此被诉 AI 的履约倾向只能靠**标记**（例如已交还的地块数用递增标记，或干脆用 `has_variable = th_gensokyo_confess_paid` 的有无来近似"是否开始履约"）。
