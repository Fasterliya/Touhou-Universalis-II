## 1. 一句话定位

**审判庭是幻想乡唯一的制裁机构：它定义什么行为算违法、把违法者打上「祟」、按轻重逐档制裁，并以「内部圣战」——幻想乡内唯一合法的战争形式——作为制裁的最高一档。**

它的常态是**判定与制裁**，圣战只是它的枪。现状的问题不是"没做"，而是**只有枪这一档**，而且玩家看不见它。

---

## 2. 玩家体验目标

| # | 目标 | 现状 |
|---|---|---|
| 1 | 被制裁方知道**自己犯了哪一条**、**还剩多久** | ❌ 只有一条隐藏的乱值在动 |
| 2 | 被制裁方有**主动出路**（自辩 / 认罪 / 求和） | ❌ 只有"打赢"或"挨判 + 计时器" |
| 3 | 制裁方**不能一次点完**：每档要有观察期、要有自伤代价、要有人肯执行 | ❌ 只有"宣战"一个按钮 |
| 4 | 玩家能**看见**审判庭：被告是谁、罪值多少、谁在领衔 | ❌ 无专属 UI；且面板被贤者议会布局占位 |
| 5 | 圣战留下"**谁在替幻想乡执法**"的痕迹 | ❌ 无归属，战争领袖由引擎按实力指派 |

## 3. 架构定案

| 项 | 定案 | 理由 |
|---|---|---|
| 形态 | **独立 IO，`unique = yes`，只在开庭时建立** | 用户拍板；平时不存在，不新增第三个常设 IO |
| 发起权 | **只有阎魔**（幻想乡 IO 领袖 T25），入口 = **幻想乡 IO 的行动面板** | 用户拍板；原有"三贤者可发起"取消 |
| 触发 | 好战价值观 `societal_value:th_gensokyo_amity_vs_belligerence` **≥ 50**（保持现状） | 用户拍板；罪名不参与触发，只参与量刑 |
| 制裁 | 四档单轨阶梯，**6 个月 / 档**（合计约 2 年劝告期） | 用户拍板（原提案 12 个月，改为 6 个月） |
| 开庭条件 | 制裁到期**仍未悔改**（取代原"越线即可开庭"） | 本次设计新增 |
| 领衔 | **世俗代理人** = 与被审判国最近的强国，自己领衔；以**独立国家标记**承载（审判庭 IO 领袖仍为阎魔） | 用户拍板 |
| 强制执行 | **三贤者强迫参战，必定加入** | 用户拍板 |
| 审判 | **判决权归阎魔**：公式算基准档 → 议会出诸国意向 → 阎魔四个宣判行动定谳（基准 ±1）；判决效果沿用现有 | 2026-10-01 第三轮拍板 |
| 偏离意向 | 阎魔按偏离量消耗幻想乡团结度 | 2026-10-01 定案 |
| 罚金 | 入**幻想乡公库**（**引擎原生 IO 宝库**：IO 定义加 `gold = yes`，UI/转账用原版）；流出端待公共工程 | 2026-10-01 定案（载体经用户指正后回 vanilla 核实） |
| 被诉方 | 自辩 / 认罪赎罪 / 战时求和 + **履约行动组**（交还领地、支付赔款） | 履约组为 2026-10-01 新增，补闭环缺口 |
| 结案 | 沿用现有：IO 解散，判决以常驻修正 / 监管国 subject 落地 | 现有实现基本不动 |

### 3.1 名称与世界观映射

| 系统概念 | 世界观表述 | 说明 |
|---|---|---|
| 彼岸 | 阎魔 · 是非曲直厅 | **纯 UI 展示**：法是彼岸给的，但彼岸不动手 |
| 世俗代理人 | 领衔执行制裁与圣战的强国 | 世俗之手；三贤者为其必然随征 |
| 罪人国家 | 被审判国 | 持「祟」标记 |
| 祟（たたり） | 制裁状态的可见载体 | 失议会权、失保护、被孤立 |
| 退治 | 内部圣战 | 执行程序，不是领土工具 |

> 「祟 / 退治」借用项目已有的四动词词汇（祭祀 / 退治 / 祟り / 废社），保持体系一致。

## 5. 阶段详解

### 5.1 阶段 0 · 越线【定案】

| 项 | 内容 |
|---|---|
| 触发 | `th_gensokyo_amity_vs_belligerence >= th_notorious_outcast_threshold_value`（现为 50） |
| 动作 | 打 `th_gensokyo_suspect_mark`（嫌疑）；通知阎魔、三贤者、受害国 |
| 不做 | **不自动立案**。越线只是"够格被纠弹"，立案是阎魔的选择 |

**为什么不用罪名触发**：用户拍板保持价值观触发。代价是触发条件与具体行为脱钩，因此以 **5.2 的罪名账本**补偿——账本不参与触发，只负责"为什么"。

> 【已知设计缺陷，接受】缘/乱轴的自然衰减被显式停用（`in_game/common/scripted_effects/th_gensokyo_notorious_effects.txt:56-64`），只有战胜归中（`peace_treaties/th_gensokyo_crusade_triumph.txt:34-39`）与宴会 -2（12 月 CD）两条下行路径。**这使"越线"接近单向棘轮**；本设计的【认罪赎罪】把归中补成第二条正常出口。

### 5.2 阶段 1 · 纠弹立案与罪名账本【定案】

**立案**（阎魔独占）：

| 项 | 内容 |
|---|---|
| 前置 | 目标持「嫌疑」标记，且非免制裁期（`th_gensokyo_sanction_immunity`） |
| 动作 | 读账本 → 生成起诉书 → 打「祟」`th_gensokyo_tarnish_mark` → 施加第 1 档谴责 |
| 表决 | **立案不需要表决**（阎魔独断）；撤销也不需要（见 5.3） |

**罪名账本**（本次设计新增，是"制裁"与"包围网"的分界线）：

在价值观上升的**现有 4 个调用点**同步记账，立案时读出来就是起诉书：

| 罪名 | 记账点（现有） | 罪值分量 |
|---|---|---|
| 非法扩张（未授权吞并 / 割地） | `on_action/th_gensokyo_chain_events.txt:314`（吞并分支） | 16 / 地块 |
| 吞并人间之里属领 | `on_action/th_gensokyo_chain_events.txt:116` | 96 |
| 征服割地 | `scripted_effects/th_gensokyo_expansion_effects.txt:37` | 3 / 地块 |
| 合法扩张（配额内） | `on_action/th_gensokyo_chain_events.txt:77` | 2 / 地块 |

需要新增记账点的罪名（**本期范围已拍板**）：

| 罪名 | 拟挂载钩子 | 分量 | 本期 |
|---|---|---|---|
| 攻击彼岸监管国 | `on_war_declared`（现有 `th_gensokyo_regulated_protection` 旁） | 30 | ✅ 做 |
| 对成员无 CB 宣战 | `on_war_declared` | 15 | ✅ 做 |
| 攻击贤者保护对象 | `on_war_declared`（现有 `th_gensokyo_free_city_protection_check` 旁） | 20 | ⬜ 延后 |
| 拒绝贤者调停 | `on_enforce_peace_declined` | 10（复用 `th_crusade_sin_refusal_value`） | ⬜ 延后 |

> 延后两项的钩子都已存在，后续补记账只需一行。

**每条罪名记录两个字段**：累计值 + 最近一次发生的年月。起诉书在 UI 上呈现为逐条列表（见《UI规格》图 1），每一条都带"是否已履约"。

### 5.3 阶段 2 · 制裁阶梯【定案】

**四档（单轨，不可跳级）：**

| 档 | 名称 | 效果 | 自伤代价（使"不能一次点完"） |
|---|---|---|---|
| 1 | **谴责** | 全体成员对目标的敌意 / 好感惩罚（外交孤立） | 幻想乡团结度月度下降；阎魔被指滥用权威 |
| 2 | **夺权** | 剥夺幻想乡议会投票权（`special_status_power` 归零 / 席位停权） | 该国的贡献与影响力停止流入全乡池（全员净损失） |
| 3 | **禁运** | 经济制裁 = **真禁运关系**（`scripted_relation` `embargo_nation`，EU5 原生机制，带 `trade_conflict` CB）**【v1.8 定案 2026-10-01：用真禁运，不作近似】** | 与目标贸易比重高的成员自身受损 → 它们在表决中反对 |
| 4 | **限张** | **扩张招致更大国际反弹**（`antagonism_received_modifier`）+ 取消贤者授权资格 **【v1.8 定案 2026-10-01：正名】** | 把目标逼向内部镇压或更激进路线 → 抗命值上升 |

> 「取消保护」（让目标失去自由市 / 贤者 / 阎魔的保护义务）**未采纳** —— 用户未选。它会让第三方直接把被制裁国吃掉，跳过审判。

**节奏：**

```
施加第 N 档 → 6 个月观察期 → 悔改判定
    ├─ 悔改（履约）→ 撤销 + 结案 + 进入考察期
    └─ 未悔改    → 解锁第 N+1 档（且需有人肯执行）
```

**悔改判定必须走【履约行为】，不能走数值** —— 6 个月内价值观不会自然下降（自然衰减被停用），若按数值判会恒为"未悔改"，四档阶梯退化成自动一路升到开庭。

| # | 履约条目 | 判定方式 | 备注 |
|---|---|---|---|
| 1 | 交还非法所得地块 | 立案时记录涉案地块与受害国，观察期末检查地块归属是否回归受害国 | 需保存 scope，见《实施计划》待验证 4 |
| 2 | 支付赔款 | 认罪 / 赔款行动写入的已付金额变量 ≥ 要求额 | — |
| 3 | 释放被吞并的国家 | 被吞并国重新存在（需立案时打标记） | 实现较绕，可后置 |
| 4 | 停止对受害国的战争 | `is_at_war_with` 判定 | 便宜可靠 |
| 5 | 自请监管 | 变量标记 | 重罚选项，直接结案 |

> **退路**：若 1 / 3 的地块归属回溯实现复杂，退化为**纯行为记账**版——"观察期内是否执行了任一履约行动 + 是否新增罪名"，不做地块归属回溯。功能略弱但不会卡死。

**升级门槛【定案：代理人领衔制】**：阎魔宣告升档 → 点名的合格强国**接受才落地**；拒绝则保留原档位，阎魔另选。理由：用一票 95 国议会来解决"不能一次点完"太笨重，用"得有人肯替你动手"来解更硬。
实现载体的不确定性见《脚本规格》待验证 2，退路为"点名即落地、代理人只能事后抗命"。

**撤销**：阎魔可独断赦免（**不需要表决**）。权力结构由此成立 —— **阎魔管宽赦，世俗管加刑**。

### 5.4 阶段 3 · 开庭与代理人【定案】

**开庭流程**：

1. 创建审判庭 IO（沿用现有 `create_international_organization`，`unique = yes`）
2. **代理人领衔**：写入国家标记 `th_gensokyo_tribunal_agent_mark`（**审判庭 IO 领袖仍为阎魔**，`set_leader_country = scope:actor` 保持现状）
3. **三贤者强制入庭**：`add_country_to_international_organization`（该效果绕过 `can_join_trigger`，是硬加；先例：`generic_actions/th_gensokyo_crusade_declare.txt:148-159` 的附庸自动入庭）
4. 成员自愿加入（沿用现有 `th_gensokyo_join_crusade`）
5. 宣战（沿用现有 `th_gensokyo_crusade_declare_war`）→ 内部圣战开始

**代理人选取规则【定案】：**

| 项 | 规则 |
|---|---|
| 候选池 | 幻想乡 IO 成员，且**非**：被告、被告盟友 / 附属 / 宗主、免制裁期国、监管国 |
| 硬门槛 | 相对实力 ≥ 1.0（不弱于被告）——否则领衔者打不赢，圣战变笑话 |
| 排序 | 与被告**距离最近**（有共同边界优先），同距取实力最强者 |
| 兜底 | 无合格候选 → 三贤者中最近者领衔（贤者必然参战，因此永不为空） |

**收益与代价**（让它值得抢、也怕被点）：

- 收益：圣战威望与贡献、审判庭内的话语权（**赔款已改为入幻想乡公库**，战后分配权待公共工程上线后再接回）
- 代价：出兵主力、战后与邻居结仇、**被反杀时免制裁期与威望大跌都算在它头上**

**设计副产品**：按"最近 + 强国"跑，幻想乡中心位置的守护国（博丽神社）天然成为默认代理人 —— 与"博丽巫女负责退治"完全吻合，规则自己长出世界观，无需硬编码。

> 【待验证 5】`international_organizations/th_gensokyo_tribunal.txt:35` 的 `promote_strongest_member_to_war_leader = yes` 决定战争领袖，**代理人不必然成为战争领袖**。本设计接受这一现状（"领衔"与"战争领袖"是两件事）；若日后要强制代理人当战争领袖，属独立改动。

### 5.5 阶段 4 · 审判（判决权归阎魔）【定案 · 2026-09-29 第三轮】

**判决结构（用户拍板：阎魔独判）**

```
战争结束 → 公式算【基准档】（罪 + 态度 + 审判法倾向）
        → 议会辩论产生【诸国意向】（从重 / 从轻）
        → 阎魔点击【宣判】四个行动之一，定谳
        → 判决偏离意向时，阎魔按偏离量付出代价
```

| 环节 | 归属 | 说明 |
|---|---|---|
| 基准档 | 公式 | 罪 + 态度 + 审判法倾向 → 0–3 |
| 诸国意向 | 审判庭议会（原 `th_gensokyo_trial_issue`） | **降级为意向**：不再决定档位，只产生"从重 89 / 从轻 34" |
| 定谳 | **阎魔（独占）** | 四个宣判行动，`allow` 限定在**基准 ±1** 内可点，其余置灰 |
| 偏离代价 | 阎魔 | 判决偏离意向 → 按偏离量消耗**幻想乡团结度**（2026-10-01 定案） |
| 超时兜底 | 自动 | 战后 N 个月阎魔未宣判 → 自动按诸国意向判决（**防卡死，必须有**） |

**为什么独判不是投票**：映姬在设定上就是独任法官（是非曲直厅没有陪审团）；而现状是"辩论只选了一套查表规则"——投票看着像审判，实际在做选择题，玩家投了个寂寞。独判把定谳变成阎魔的一个真实动作，同时用"偏离意向有代价"保住诸国意见的分量：**民意不是否决权，是专断的价签。**

**为什么用四个行动而不是选择器**：GenericAction 按钮名静态，且 `select_trigger` 只能选国家 / IO / 地点这类对象——**"档位"不是一个可被选择的实体**。四个宣判行动各自带 `allow`，阎魔打开面板看到的是一排"宣判·XX"，只有基准 ±1 内的两个亮着——**那一屏本身就是裁量范围的可视化**，比任何 tt 都直白。

**判决落实（现有实现，本次不改）**

| 档 | 执行内容 | 出处 |
|---|---|---|
| 0 赔款破产 | 国库半数转出 + 破产修正 2 年 | `scripted_effects/th_gensokyo_crusade_effects.txt:166-188` |
| 1 归还 | `th_gensokyo_trial_return_lands_effect`（内部 `change_location_owner = previous_owner`，按上一个所有者回滚） | 同文件 :140, :190-196 |
| 2 削弱 | `th_gensokyo_weakness_modifier` 5 年 | 同文件 :198-207 |
| 3 监管国 | 国库清零 + 刑期 + `make_subject_of type = subject_type:th_gensokyo_regulated_state`（宗主 = 阎魔） | 同文件 :209-228 |
| 附加 | 团结按档扣减、审判完成必获团结（审判法影响） | 同文件 :231-300+ |

1. **`th_gensokyo_pool_var` 这个变量作废**（2026-10-01 前稿的拟名）。原生宝库是引擎资产，不是 IO 变量；两者别混。
2. ~~**加 `gold = yes` 之前必须先补一个 GUI block**：……本项目整份替换了 `organization_panel` 且**没有保留这个 block**……~~ **【v1.8 修正，2026-10-01】准确表述**：那份"整份替换 `panel_content`"的面板文件**只作用于贤者议会自己**（vanilla 机制 = `gui/panels/organization/<IO 类型 key>.gui` 一类型一文件；R1 批已核实）。**幻想乡 IO 走 vanilla 默认面板**，而默认面板的宝库分页按钮默认 `visible = no`（`common.gui:234-236`）—— 所以现状确实是"没有入口往幻想乡 IO 宝库里放钱"。**修法三件**：① 在 `th_gensokyo_io.gui` 里**新写一行** `blockoverride "organization_treasury_tab_visible" { visible = yes }`；② IO 定义加 `gold = yes`；③ IO 修正加 `unlock_contribute_to_organization_treasury = yes`（vanilla 此解锁只由 HRE 法律给，`20_hre.txt:193/311`）。**不需要重建宝库分页本体，也不涉及贤者议会面板。**

## 6. 被诉方三出路【定案】

| 出路 | 可用时机 | 机制 | 代价 |
|---|---|---|---|
| **自辩** | 立案后，每档一次 | 消耗个人影响力逐条反驳罪名；反驳全部成立 → 撤销当前档、案情结案 | 影响力（= 议会投票权重，掉的是政治资本） |
| **认罪赎罪** | 立案后任意时点 | 支付代价 → 价值观归中（0）→ 撤销全部档位 → 进入 N 年考察期（缓刑） | 认罪价 = 基础价 ×（1 + 0.5 × 已施加档数）；考察期内再犯，罪值翻倍、直接开庭 |
| **战时求和** | 圣战期间 | 认罚 → 价值观跌破 50 → 现有 `auto_leave_trigger` 触发 → 审判庭失去正当性、自动解散 | 代价介于"提前认罪"与"战败判决"之间 |

**自辩需要"证据"**：反驳要基于已有状态判定，不能空转。可举证的例子：该次扩张是否持有贤者授权、是否处于异变期间（豁免）、受害国是否先动的手。这些变量在现有链路上基本都有。

### 6.1 履约行动组（2026-10-01 新增，补一个真缺口）

**缺口的原话**：悔改判定按【履约行为】判（§5.3），但被诉方**没有对应的按钮**——玩家知道要悔改，却不知道能做什么、在哪里做。设计里缺了"从知道要悔改到能悔改"这一步。

| 行动 | 对应履约条目 | 机制 |
|---|---|---|
| **履约·交还领地** | 已归还非法所得 | `select_trigger` 选涉案地块 → `change_location_owner = previous_owner`（**现成写法**，判决效果 `crusade_effects.txt:140` 在用） |
| **履约·支付赔款** | 已付赔款 | 付款 → 入公库；累计写入 `th_gensokyo_confess_paid`，供悔改判定读 |
| *（不设按钮）停止战争* | 已停止对受害国的战争 | 走现有和约机制；案卷区红字提示"仍在与受害国交战"，不新增行动 |
| **自请监管**（可选） | 自请监管 | 直接接受档 3 刑期，换取免于开庭——最重的止损选项 |

**与"认罪赎罪"的关系**：履约是**分期**（逐条做到，逐步满足悔改条件，便宜但要等），认罪是**一次结清**（贵，但当场撤销全部制裁）。玩家会算这笔账——这就是被诉方真正有意义的选择，也是"6 个月观察期里我该干嘛"的答案。

**「战时求和」把现有死代码救活**：`international_organizations/th_gensokyo_tribunal.txt:77-82` 的 `auto_leave_trigger`（目标价值观跌破阈值 → 全体退出）目前几乎不可能触发，本设计把它变成圣战的主要出口之一。
